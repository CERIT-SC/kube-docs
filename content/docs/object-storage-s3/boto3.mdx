[Boto3](https://boto3.amazonaws.com/v1/documentation/api/latest/index.html) library is a Python Software Development Kit for S3 service. It allows developers to create, configure, and manage S3 services. The library provides a simple and intuitive interface for interacting with CESNET S3 resources.
