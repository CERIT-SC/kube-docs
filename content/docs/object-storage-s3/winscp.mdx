title: WinSCP - S3 usage
---

[WinSCP](https://winscp.net/eng/index.php) is a popular SFTP and FTP client for Microsoft Windows. It allows you to transfer files between your local computer and remote servers using FTP, FTPS, SCP, SFTP, WebDAV, or S3 file transfer protocols.

## WinSCP installation
Please use the package directly from the [WinSCP](https://winscp.net/eng/download.php) website for installation. The installation process is straightforward and does not require any special settings.

## WinSCP configuration

Run the tool.

![s3client](/img/data-care/winscp/winscp_setup1_v2s_en.png)

To connect to storage, go to the **Tabs** option in the main menu and select **New Tab** (or **Remote Tab**, Ctrl+N).

![s3client](/img/data-care/winscp/winscp_setup2_v2s_en.png)

In the drop-down menu **File protocol** select `Amazon S3`.

![s3client](/img/data-care/winscp/winscp_setup3_v2s_en.png)

Next, enter the **Host name** as `s3.clX.du.cesnet.cz`, replacing **X** with the cluster number associated with your S3 account. Port `443` will be automatically pre-filled. Copy the `access_key` into the **Access key ID** field and the `secret_key` into the **Secret access key** field - both of these keys were provided to you in an encrypted format by the administrators or self-generated in the Gatekeeper web interface.

![s3client](/img/data-care/winscp/winscp_setup4_v2s_en.png)

Select **Advanced** settings.

![s3client](/img/data-care/winscp/winscp_setup5_v2s_en.png)

Leave the **Default region** field blank! Select **URL Style** `Path` and click **OK**. Then, click **Save** to name and save your configuration. Then, click **Login** to connect to the storage.

![s3client](/img/data-care/winscp/winscp_setup6_v2s_en.png)

Once the storage is connected, you will see a list of your buckets on the right side (you can also create new buckets).
