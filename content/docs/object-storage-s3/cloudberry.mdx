title: CloudBerry Explorer for Amazon S3
---

[CloudBerry Explorer](https://cloudberry-explorer-for-amazon-s3.en.softonic.com/) is an intuitive file manager that allows you to manage your S3 account as if it were just another folder on your local drive. The program features a dual-pane interface and functions like an FTP client, with each pane dedicated to a single folder. These locations are flexible and can be switched to suit your needs: a local computer and a remote S3 server, two local folders, or even two S3 accounts. 

## Cloudberry Installation
You can download the .exe installer from [the oficial Cloudberry website](https://cloudberry-explorer-for-amazon-s3.en.softonic.com/). When you start the program, you will be informed about the registration options. Registration is free, and once completed, you will receive a key via email, after which all pop-ups will be disabled.

<Callout type="warn" icon="⚠️">
The FREE version of CloudBerry does not support Multipart Upload or Multithreading, meaning it cannot handle files larger than 5GB. Encryption and compression are also only available in the PRO version.
</Callout>

## Cloudberry Configuration
Storage configuration can be done through **1. File** menu, where you select **2 Add New Account**. Do not choose the Amazon S3 Accounts option, as it does not allow you to enter the service endpoint and other necessary details!

![s3client](/img/data-care/cloudberry/cloudberry1.png)

In the next window Select Cloud Storage - **1. S3 Compatible** option.

![s3client](/img/data-care/cloudberry/cloudberry2.png) 

In the next step you have to fill in S3 credentials including the S3 endpoint.

![s3client](/img/data-care/cloudberry/cloudberry3.png)

Next, you can begin uploading your data. From the **1. Source selector** choose your **2. S3 account** that has been previously configured.

![s3client](/img/data-care/cloudberry/cloudberry4.png)

First you need to **1. Create new bucket** and then you can upload your data into it.

![s3client](/img/data-care/cloudberry/cloudberry5.png)
