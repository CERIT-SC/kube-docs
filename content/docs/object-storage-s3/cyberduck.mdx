[CyberDuck](https://cyberduck.io/) is a versatile tool that supports various cloud storage providers. It is compatible with FTP, SFTP, WebDAV, OpenStack, OneDrive, Google Drive, Dropbox, and more. 

## Installation
You can download the exe installer from the [CybeDuck webpage](https://cyberduck.io/) and follow the installation steps.

## Configuration

New storage can be set up by clicking the **New Connection** button in the left menu.

![s3client](/img/data-care/cyberduck/cyberduck1en.png)

In the following window you select **Amazon S3** and enter the server URL s3.clX.du.cesnet.cz, where `X` corresponds to the number asociated with your S3 account (e.g. `cl4`). Next, enter your `acces_key` and `secret_key` and then click the **Connection** button.

![s3client](/img/data-care/cyberduck/cyberduck2en.png)

Next, you can create a bucket. The main directory can only contain directories (buckets).

![s3client](/img/data-care/cyberduck/cyberduck3en.png)

While creating the bucket, keep the default region.

![s3client](/img/data-care/cyberduck/cyberduck4en.png)
