## Úvod do API

Tato dokumentace poskytuje podrobné pokyny pro generování a používání **API klíčů** pro přístup k lokálně běžícím velkým jazykovým modelům (LLM) na infrastruktuře e-INFRA CZ, konkrétně přes rozhraní Open-WebUI [https://chat.ai.e-infra.cz](https://chat.ai.e-infra.cz). Průvodce je určen pro výzkumníky a vědce, kteří chtějí tyto modely integrovat do svých aplikací, skriptů nebo AI workflow prostřednictvím API.

Pro přístup k službě Open-WebUI a generování API klíče musíte splnit následující předpoklady:

* Platný účet MetaCentrum (pro české výzkumné instituce)  
* nebo aktivní účet Masarykovy univerzity (pokud jste její součástí).

Pro podrobný popis dostupných modelů viz [dokumentace Chat AI](../ai-as-a-service/chat-ai)


## Vytvoření API klíče

API klíče slouží jako autentizační tokeny pro bezpečný přístup k API endpointu Open-WebUI. Postupujte podle následujících kroků pro generování a použití API klíče:

**Postup krok za krokem**

1. Přejděte do sekce Nastavení v rozhraní Open-WebUI [https://chat.ai.e-infra.cz](https://chat.ai.e-infra.cz).  
2. Přejděte do části Účet (Account).  
3. Klikněte na API klíče (zobrazit).  
4. Ignorujte JWT token a vyberte možnost API key – buď vytvořte nový, nebo zobrazte existující.  
5. Zkopírujte vygenerovaný API klíč a uložte jej bezpečně.  
6. Použijte tento klíč v API požadavcích pro autentizaci a přístup ke službám Open-WebUI.  
7. Základní endpoint pro Open-WebUI API je: [https://llm.ai.e-infra.cz/v1/](https://llm.ai.e-infra.cz/v1/). Tento endpoint dodržuje specifikaci OpenAI API, což zajišťuje kompatibilitu s mnoha existujícími frameworky a aplikacemi pro LLM.



## Použití API klíče

### Výpis dostupných modelů

Před dotazováním modelu se ujistěte, že používáte správný název modelu. Chcete-li získat seznam všech dostupných modelů na infrastruktuře e-INFRA CZ, spusťte následující příkaz pomocí `curl` a `jq`.  
Nahraďte `${E_INFRA_API_TOKEN}` vaším skutečným tokenem.


```shell
curl -H "Authorization: Bearer ${E_INFRA_API_TOKEN}" https://llm.ai.e-infra.cz/v1/models | jq .data[].id
```

Očekávaný výstup (příklad):

```
"llama3.3:latest"
"llama3.3:70b-instruct-fp16"
"deepseek-r1:32b-qwen-distill-fp16"
"qwen2.5-coder:32b-instruct-q8_0"
"aya-expanse:latest"
```

Tento seznam obsahuje identifikátory modelů (`id`), na které lze dotazovat přes API. Identifikátory se řídí konvencí pojmenování, která obvykle zahrnuje:

* Název modelu (např. `llama3.3`, `qwen2.5-coder`).
* Označení kvantizace (např. `fp16`, `q8_0`), které udává, jak je model optimalizován pro inferenci (důležité pro výkon a spotřebu zdrojů).
* Variantu nebo revizi (např. `:latest`, `:70b-instruct-fp16`).

### Příklad API požadavku 

Níže je uveden příklad, jak použít API klíč k dotazování modelu LLama 3.3 (llama3.3:latest) pomocí chat completions požadavku:


```
curl https://llm.ai.e-infra.cz/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${E_INFRA_API_TOKEN}" \
  -d '{
    "model": "llama3.3:latest",
    "messages": [
      {
        "role": "user",
        "content": "Explain the impact of machine learning on climate research in 100 words or less."
      }
    ]
  }'
```

Očekávaný výstup (příklad):

```bash
{
  "id": "chatcmpl-XYZ123",
  "object": "chat.completion",
  "model": "llama3.3:latest",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "Machine learning (ML) is revolutionizing climate research by unlocking unprecedented insights..."
      },
      "index": 0,
      "finish_reason": "length"
    }
  ]
}
```



## Integrace s frameworky

API e-INFRA CZ LLM je navrženo tak, aby bylo kompatibilní se specifikací OpenAI API, což znamená, že jej lze integrovat do frameworků původně vytvořených pro služby OpenAI.

**Příklad integrace s PyDanticAI**

PyDanticAI je framework, který zjednodušuje práci s LLM pomocí modelů kompatibilních s OpenAI. Pro autentizaci vůči e-INFRA CZ LLM endpointu použijte následující konfiguraci:

Příklad konfigurace `PydanticAI` pro integraci s naším API (pro ostatní frameworky použijte obdobné nastavení):







```python
from pydantic_ai_provider import OpenAIModel, OpenAIProvider
import os

model = OpenAIModel(
    'deepseek-r1',
    provider=OpenAIProvider(
        base_url="https://llm.ai.e-infra.cz/v1",
        api_key=os.getenv("E_INFRA_API_TOKEN"),
    ),
)
```

Kromě PyDanticAI lze podobné konfigurace použít také pro:

* LangChain
* LlamaIndex
* Aplikace založené na FastAPI
* Jakékoli další frameworky nebo klienty, které podporují custom endpointy OpenAI API.


## Reasoning modely v API

Některé modely jsou **hybridní** a podporují jak *reasoning (thinking)*, tak *non-reasoning* režimy .

V chatovacím rozhraní je většina hybridních modelů přednastavena pro režim reasoning, což znamená, že můžete vidět mezivýstupy `thinking` před tím, než je vrácena finální odpověď. V API však výchozí chování závisí na konkrétním modelu.


### DeepSeek v3.2

Ve výchozím nastavení **DeepSeek v3.2** běží *bez* povoleného reasoning. Chcete-li reasoning povolit, předávejte další parametry přes `chat_template_kwargs`:


```bash
curl https://llm.ai.e-infra.cz/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer xxx" \
  -d '{
    "model": "deepseek-v3.2",
    "messages": [
      {
        "role": "user",
        "content": "What are 5 creative things I could do with my kids'' art? I don''t want to throw them away, but it''s also so much clutter."
      }
    ],
    "chat_template_kwargs": {
      "thinking": true
    }
  }'
```

Pro pohodlí — a pro prostředí, kde nelze použít `chat_template_kwargs` (například u některých AI agentů) — také poskytujeme speciální variantu pro reasoning s názvem **`deepseek-v3.2-thinking`**, která je trvale nastavena do režimu thinking.


### GLM-4.7

Na rozdíl od toho model **GLM-4.7** ve výchozím nastavení zapíná režim reasoning. Pokud chcete režim reasoning vypnout a vrátit pouze finální odpověď, explicitně jej deaktivujte pomocí `chat_template_kwargs`:

```bash
curl https://llm.ai.e-infra.cz/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer xxx" \
  -d '{
    "model": "glm-4.7",
    "messages": [
      {
        "role": "user",
        "content": "What are 5 creative things I could do with my kids'' art? I don''t want to throw them away, but it''s also so much clutter."
      }
    ],
    "chat_template_kwargs": {
      "enable_thinking": false
    }
  }'
```

Tyto možnosti použijte k řízení toho, zda jsou v odpovědích API zahrnuty mezikroky reasoning, podle potřeb vaší aplikace.
