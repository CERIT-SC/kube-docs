## Úvod

Open WebUI je rozhraní chatbota s umělou inteligencí, které poskytuje bezpečný, on-premise přístup k pokročilým jazykovým modelům pro chatování, programování, zpracování dokumentů a generování obrázků. Stejné modely jsou přístupné prostřednictvím zdokumentovaného REST API a lze je propojit s dalšími aplikacemi, jako je například Visual Studio. Tato příručka obsahuje pokyny, jak se přihlásit, používat modely, generovat obrázky a vytvořit API klíč. Naše služby AI běží kompletně v rámci zabezpečené infrastruktury e-INFRA CZ – vaše data toto prostředí nikdy neopustí.

## Příklady
Níže najdete podrobný návod, jak používat LLM modely v Open WebUI v různých situacích.

### Generování obrázků

Generujte AI obrázky z textových promptů.  
* **Vyberte** model pro generování textu (např. `GPT-OSS-120B`) v rozbalovacím menu vlevo nahoře. 
* **Klikněte** na **Ikonu integracín** pod polem pro prompt → Přepněte **Image** posuvník na  **ON**.  
  
<div class="w-110">  
![image-webui](/img/ceritsc/image-webui.png)  
</div>  

* Zadejte svůj textový prompt (např. `Čtyři jezdci apokalypsy`).  
* Stiskněte Enter nebo klikněte na Odeslat.
* Poté můžete zadávat dodatečné instrukce k úpravě vytvořeného obrázku (např. `Zvýrazni neonová světla, přidej létající auta`). Po každé úpravě znovu stiskněte Enter.
* **Výsledek**: Vygenerovaný obrázek se zobrazí přímo v chatu.


### Editor obrázků

Upravujte nahrané obrázky pomocí multimodálních modelů.

* Vyberte multimodální model (např., `RedHat AI Scout`) z nabídky modelů.
* Klikněte na ikonu **+** → **Nahrát soubory** → Vyberte obrázek (JPG/PNG) 

<div class="w-110">
![uploadfiles-webui](/img/ceritsc/uploadfiles-webui.png)
</div>

* Nahrajte obrázek, který chcete upravit.
* **Klikněte** na **ikonu integrace** pod dotazom → Přepněte **Image** posuvník  do polohy **ZAPNUTO**. 

<div class="w-110">
![image-webui](/img/ceritsc/image-webui.png)
</div>

* Zadejte příkaz pro úpravu: např., `Vyměň pozadí přiloženého obrázku na …`.
* Stiskněte Enter nebo klikněte na Odeslat.

* **Výsledek:** Upravený obrázek se zobrazí v chatu.

    
### Převod obrazu na text (OCR skener)
Extrahuje text z obrázků.

* Vyberte model pro generování textu (např., `Gemma 3` nebo `RedHatAI Scout`)  
* Klikněte na ikonu **+** → **Nahrát soubory** → Vyberte obrázek (JPG/PNG)  

<div class="w-110">
![uploadfiles-webui](/img/ceritsc/uploadfiles-webui.png)
</div>

* Nahrajte obrázek obsahující text (např. skenovaný dokument, PDF nebo fotografii).
* Zadejte pokyn pro OCR, např., `Extrahuj veškerý text z tohoto obrázku doslovně, zachovávající zalomení řádků.`
* Stiskněte Enter nebo klikněte na Odeslat.
* **Výsledek:**  Extrahovaný text se zobrazí jako odpověď.


### Python Sandbox pro matematické/programovací úlohy
Spouštějte Python pro matematické nebo programovací úlohy (*ne pro obecné programování*).  
* Vyberte jakýkoli model podporující **Nástroje** (např., `GPT-OSS-120B`).
* Klikněte na **ikonu integrace** → **Nástroje** → Přepněte **Python Sandbox** do polohy **ZAPNUTO**

<div class="w-110">
![python-webui](/img/ceritsc/python-webui.png)
</div>

* Zadejte svůj požadavek, např.: `Vyřeš tuto sudoku hádanku pomocí Pythonu: [[5][3][0][0][7][0][0][0][0], ...]`.
* Stiskněte Enter nebo klikněte na Odeslat.
* **Výsledek**: Textový výstup (např. vyřešená hádanka)
<Callout type="info">
⚠️  **Obecné programování je zakázáno.**  Používejte výhradně pro specifické problémy, kde Python může poskytnout efektivní **textové řešení** (např. matematické výpočty, transformace dat). 
</Callout>

## Vytvoření API klíče

Pro používání API Open-WebUI je potřeba vygenerovat API klíč.

1. Přejděte do sekce Nastavení v rozhraní Open-WebUI.
2. Přejděte na Účet.
3. Klikněte na API klíče (zobrazit).
4. Ignorujte JWT token a zvolte API klíč – buď vygenerujte nový, nebo zobrazte existující.
5. Zkopírujte vygenerovaný API klíč a bezpečně si ho uložte.
6. Tento klíč používejte v API požadavcích k ověření a přístupu ke službám Open-WebUI.
7. Adresa koncového bodu (endpoint) API je: [https://chat.ai.e-infra.cz/api/](https://chat.ai.e-infra.cz/api/).

Pro rozhraní API byste měli zjistit přesné názvy modelů pomocí příkazů jako např. `curl` a `jq`, přičemž TOKEN nahraďte svým skutečným tokenem.

```shell
curl -H "Authorization: Bearer TOKEN" https://chat.ai.e-infra.cz/api/models | jq .data[].id
```

Uvidíte výstup podobný tomuto:

```
"llama3.3:latest"
"llama3.3:70b-instruct-fp16"
"deepseek-r1:32b-qwen-distill-fp16"
"qwen2.5-coder:32b-instruct-q8_0"
"aya-expanse:latest"
```

Poté použijte například `llama3.3:latest` jako název modelu v API.

Níže je uveden příklad konfigurace PydanticAI pro integraci s naším API (podobné nastavení použijte i pro jiné frameworky):

```python
model = OpenAIModel(
    'deepseek-r1',
    provider=OpenAIProvider(
        base_url='https://chat.ai.e-infra.cz/api',
        api_key=os.getenv('E_INFRA_API_TOKEN'),
    ),
)
```

## Funkce Knowledge (Alpha)

Open WebUI obsahuje experimentální *Knowledge Function*, která v podstatě představuje systém [RAG (Retrieval-Augmented Generation)](https://en.wikipedia.org/wiki/Retrieval-augmented_generation). Tato funkce umožňuje uživatelům nahrávat vlastní texty a dotazovat se modelu, který generuje odpovědi na základě těchto nahraných dat.

V současné době funkce Knowledge podporuje pouze globální konfiguraci, což znamená, že pro všechny uložené texty je používán jeden společný embedding model.Stále vyhodnocujeme, které embedding modely jsou pro tento účel nejvhodnější. Klíčovým omezením je, že při změně embedding modelu je nutné znovu zpracovat všechny dříve nahrané texty, protože systém RAG vyžaduje konzistentní embeddingy pro správné fungování.Z tohoto důvodu není tato funkce doporučena pro produkční použití a je určena především pro testování a náhled.

Další výzvou je nalezení vhodných embedding modelů, které podporují češtinu a zároveň velké vstupní kontexty.Většina dostupných modelů je omezena na vstup o délce 512 tokenů, což je pro delší texty nevýhodné, protože je nutné obsah rozdělit na malé fragmenty – často příliš malé na to, aby bylo možné generovat kvalitní a přesné odpovědi.

Ačkoli bychom mohli integrovat externí embedding modely, například OpenAI `text-embedding-3-small`, tento přístup by ohrozil ochranu dat, protože by znamenal odesílání dat třetí straně.



## Data Privacy

V Open WebUI jsou nyní označení modelů standardizována pro lepší přehlednost. Všechny lokální modely jsou správně označeny jako interní, což zajišťuje konzistentní a přehlednou kategorizaci.

Všechny modely, ke kterým mají uživatelé přístup, běží na naší vlastní infrastruktuře, a data související s inferencí tedy neopouštějí naše systémy. Můžeme však poskytnout přístup i k externím modelům – například GPT-4o – na základě speciální dohody. V takových případech jsou data pochopitelně přenášena třetí straně.

Systém inference Ollama má veškeré logování požadavků a odpovědí zcela vypnuté. Naopak systém vLLM loguje požadavky a odpovědi pouze po dobu, kdy běží příslušný Pod.

Samotné Open WebUI ve výchozím nastavení loguje na úrovni INFO, což znamená, že údaje o požadavcích a odpovědích se neukládají. Občas, když je potřeba provést diagnostiku, může být úroveň logování dočasně zvýšena na DEBUG. V takových případech jsou data o požadavcích a odpovědích ukládána až do restartu Podu – obvykle při nasazení nové verze.

K těmto logům mají přístup pouze systémoví administrátoři a nikam jinam se nepřenášejí.

Uložené konverzace jsou uchovávány v databázi PostgreSQL hostované v rámci naší infrastruktury. Když je konverzace smazána, měla by být odstraněna také z databáze – i když jsme samostatně neověřili, zda to WebUI zcela správně provádí. Databáze je zálohována do úložiště S3 na CESNETu s 30denní retenční lhůtou, což znamená, že starší zálohy jsou po 30 dnech odstraněny. Teoreticky tedy bude smazaná konverzace během této lhůty definitivně odstraněna. Přístup k tomuto systému mají opět pouze administrátoři.

Všichni administrátoři mají podepsanou NDA (dohodu o mlčenlivosti).


## Praktický průvodce používáním AI chatů

Jako vědec určitě nejste nováček ve vyhledávání informací a odborného poradenství, které vám pomáhá při práci. Při komunikaci s AI chatboty je klíčem k získání kvalitních výsledků efektivní formulace zadání. V tomto průvodci si ukážeme osvědčené postupy, jak vytvářet kvalitní prompty a vést produktivní konverzace s AI.

### Proč záleží na správném zadání 
Špatně formulované zadání může vést k podprůměrné odpovědi. AI chatboty jsou tak dobré, jak dobrý je vstup, který obdrží. Poskytováním jasných a srozumitelných promptů můžete získat přesnější a relevantnější výsledky.

### Jak efektivně komunikovat s AI
Interakce s chatovacími modely je podobná komunikaci s lidmi. Kvalita odpovědi závisí na jasnosti a konkrétnosti vašeho zadání. Nemusíte řešit složitost – zaměřte se na popis úkolu a kladení správných otázek.

### Základní principy komunikace
1.	**Definujte svůj cíl**: Jasně uveďte, čeho chcete dosáhnout. Čím konkrétnější budete, tím lepší odpověď získáte. Vyhýbejte se vágním nebo příliš obecným zadáním, která mohou vést k neuspokojivým výsledkům.
2.	**Poskytněte kontext**: Uveďte relevantní informace, které mohou AI pomoci lépe pochopit úkol a poskytnout přesnější odpověď. Kontext pomáhá AI pochopit účel a význam vašeho dotazu.
3.	**Specifikujte podobu výstupu**: Uveďte, jak má odpověď vypadat – například délku, styl nebo tón. Tím zajistíte, že výstup bude odpovídat vašim potřebám.
4.	**Vyberte vhodný dostupný jazykový model**: Vyzkoušejte více modelů a porovnejte výsledky.

### Nechte AI pomoci s tvorbou promptů
1.	**Začněte základní myšlenkou**: Místo toho, abyste se snažili prompt složitě vymýšlet, požádejte AI, aby vám s jeho tvorbou pomohla. Například: „Vytvoř kvalitní prompt pro chatbota, který mi pomůže psát poutavé články na témata produktivity pro mé kolegy.“
2.	Upřesněte účel: Přidejte kontext, jak hodláte prompt použít, například: „Tento prompt budu používat k psaní článků o produktivitě pro své kolegy.“
3.	Vylaďte výsledek: AI vám poskytne kompletní prompt, který můžete použít tak, jak je, nebo jej dále upravit podle svých potřeb.

### Jak vést produktivní konverzace s AI
1.	**Začněte kvalitním promptem**: Vytvořte co nejlepší zadání podle postupů uvedených výše.
2.	**Vyhodnoťte odpověď**: Projděte si odpověď a určete, co by se dalo zlepšit. AI nemusí hned napoprvé dodat přesně to, co potřebujete.
3.	**Upřesňujte svou žádost**: Pokračujte v konverzaci a poskytněte konkrétní zpětnou vazbu, například: „Napiš to stručněji“ nebo „Použij formálnější tón.“
4.	**Opakujte proces**: Iterujte, dokud nedosáhnete požadovaného výsledku. Ptejte se, dávejte zpětnou vazbu a dolaďujte prompt, abyste získali co nejlepší odpověď.

### Vylepšování promptů pomocí rolí a detailů 
1.	**Přiřaďte AI roli**: Poskytněte kontext tím, že AI přiřadíte určitou roli, například: „Chovej se jako zkušený copywriter s 15 lety praxe.“ To pomůže AI vytvářet relevantnější a propracovanější odpovědi.
2.	**Popište problém do detailu**: Jasně vysvětlete úkol nebo problém, se kterým potřebujete pomoci. Uveďte co nejvíce kontextu, aby AI přesně pochopila, co potřebujete.
3.	**Uveďte požadovaný formát výstupu**: Označte, jak má být odpověď strukturovaná, například jako seznam, tabulka nebo souvislý text.
4.	**Definujte tón a styl**: Uveďte, v jakém tónu má být odpověď napsána, například: „Napiš to přátelským a přístupným tónem“ nebo „Použij formální a technický styl.“

### Používání příkladů pro lepší výsledky
1.	**Poskytněte ukázku**: Uveďte příklad nebo vzor toho, co chcete. Pomůže to AI lépe pochopit vaše požadavky a dodat přesnější odpověď.
2.	**Používejte pozitivní instrukce**: Místo toho, abyste říkali, co AI nemá dělat, zaměřte se na to, co má dělat. Například: „Použij jednoduchý jazyk“ místo „Nepoužívej odborný žargon.“
3.	**Vyhněte se protichůdným pokynům**: Buďte ve svých požadavcích konzistentní a vyhněte se rozporům v zadání.
4.	**Nechte AI klást otázky**: Podpořte AI, aby se ptala v případě nejasností nebo potřeby upřesnění. Pomůže to zajistit přesnější a relevantnější odpověď.
