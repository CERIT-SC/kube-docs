## AI for Science. Built for Researchers. Run securely in e-INFRA CZ.

CERIT-SC hosts large language models for the Czech research and academic community, **free of charge and inside the national e-INFRA CZ infrastructure**. Use them as a chat in your browser, call them from your own scripts, or plug them into your code editor. The models work with text and code; some also read images or transcribe speech.

## Choose a model

Models differ in their capabilities, response time, and resource needs.
Start with a model suited to your task and evaluate its output on a
small, representative sample.

- **Text and code models** support tasks such as drafting, classification,
  information extraction, and programming assistance.
- **Multimodal models** can also process images, where supported.
- **Embedding models** convert text into numerical representations
  for semantic search and retrieval-augmented generation (RAG).
  RAG supplies retrieved documents as context for a model's answer.

See the [model catalogue](./llm-models) for all models, their capabilities and context sizes, and the [live status page](https://llm.ai.e-infra.cz/status/) for what is running right now. The [hardware page](./hardware) describes the GPU systems behind the service.

### Model changes and reproducibility

Models are upgraded and retired, so a specific version may not stay available for the whole length of your project. An [alias](./llm-models#model-aliases) keeps the name stable when the model behind it changes; it does not keep the behaviour or the results the same.

For work that feeds into a publication:

- Record the exact model identifier and its metadata, not only the alias. The API guide shows how to [retrieve model metadata](./ai-api#getting-model-metadata-via-the-api).
- Save prompts, input data, generation settings, dates and outputs as your data-management plan requires.
- Validate the workflow again after a model change.

If your project depends on one specific model version, write to [k8s@cerit-sc.cz](mailto:k8s@cerit-sc.cz) before you start.

## Research data and privacy

Standard hosted models run within e-INFRA CZ. External search tools
and separately arranged third-party services can involve sending
information outside this infrastructure.

Data handling also depends on how you access the service:

- **Chat interface:** conversations and uploaded files are stored
  by the service. Review the retention and deletion information
  before uploading documents.
- **Direct API:** the documented API route bypasses the chat interface's
  conversation storage. This does not, by itself, establish that a
  workflow meets your project's data-protection requirements.

The chat interface is intended for general research assistance and
is not certified for protected data. Before using sensitive,
personal, or otherwise restricted data, contact
[k8s@cerit-sc.cz](mailto:k8s@cerit-sc.cz) to discuss a suitable setup.

Read the [AI data privacy policy](./ai-data-privacy) for details
on external services, storage, logging, and retention.


## Share computing resources responsibly


Many researchers share the same GPUs, so response times vary with demand.

- **Pick the smallest model that does the job.** Move to a larger one only when your evaluation shows a benefit.
- **Keep batch workloads controlled.** Limit concurrent requests and respect the rate limits.
- **Do not switch models automatically** in response to short-term utilisation figures on the status page.
- **Talk to us before large runs.** Schedule heavy batch processing outside peak hours, and agree independent benchmarks with the support team in advance, as the [Chat AI guide](./chat-ai#shared-resources-and-benchmarking) requires.

You can review your API token consumption in the
[usage dashboard](https://llm.ai.e-infra.cz/usage/).
This dashboard does not include chat-interface usage.
