## Úvod
AI infrastruktura CERIT-SC zpřístupňuje velké jazykové modely (LLM) prostřednictvím standardních API protokolů, což vám umožňuje integrovat výkonné AI asistenty přímo do vašeho lokálního vývojového prostředí. Propojením vašich nástrojů s naším backendem můžete využívat výkonné modely (například qwen3-coder nebo gpt-oss-120b) pro programátorské úlohy, aniž byste je museli provozovat na vlastním hardwaru nebo spoléhat na externí komerční poskytovatele.

Tato kapitola popisuje, jak nakonfigurovat dva populární nástroje tak, aby komunikovaly s naším API.

<Callout type="info"> 
Prerekvizita: Před pokračováním se ujistěte, že jste vygenerovali API klíč z  [AI Chat WebUI](../ai-as-a-service/chat-ai). Tento klíč budete potřebovat k autentizaci vašeho klienta.
</Callout>

## Claude Code

<Callout type="info"> 
Claude Code lze použít také v [Jupyter noteboocích](../web-apps/jupyterhub#claude-code-integration-in-jupyter-notebook) 
</Callout>

Můžete nasadit [Claude Code](https://github.com/anthropics/claude-code) a nakonfigurovat jej tak, aby fungoval s našimi modely tím, že jej nasměrujete na náš API endpoint.

### Instalace

Nejprve nainstalujte Claude Code pro váš operační systém podle oficiálních pokynů v upstream repozitáři:

- [Claude Code – Začínáme](https://github.com/anthropics/claude-code?tab=readme-ov-file#get-started)

Ujistěte se, že `claude` CLI je po instalaci k dispozici ve vaší  `$PATH`.

#### Instalace na Linux (včetně Windows WSL)

Tato instrukce platí pro Linux i Windows Subsystem for Linux (WSL).

##### 1. Nainstalujte Claude Code

Nainstalujte Claude Code pomocí oficiálního instalačního skriptu:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Po úspěšném dokončení instalace byste měli vidět výstup podobný následujícímu:

```
Setting up Claude Code...

✔ Claude Code successfully installed!

  Version: 2.1.5
  Location: ~/.local/bin/claude

  Next: Run claude --help to get started

✅ Installation complete!
```

##### 2. Spusťte Claude a ukončete průvodce nastavením

Poprvé spusťte Claude:

```bash
claude
```

- Projděte výběrem schématu syntaxe.
- Jakmile se dostanete na obrazovku **“Select login method”** ukončete aplikaci stisknutím **Ctrl+C třikrát**.

Tento krok vygeneruje počáteční konfigurační soubor bez dokončení úvodního nastavení.

##### 3. Ručně dokončete úvodní nastavení

Otevřete konfigurační soubor Claude:

```bash
vim ~/.claude.json
```

Na **konec souboru** přidejte následující vlastnost:

```json
"hasCompletedOnboarding": true
```

<Callout type="warn">
- Ujistěte se, že předchozí poslední vlastnost končí čárkou.
- JSON musí zůstat platný.
</Callout>

Příklad správně aktualizovaného souboru `~/.claude.json`:

```json
{
  "installMethod": "native",
  "autoUpdates": false,
  "cachedGrowthBookFeatures": {
    "tengu_1p_event_batch_config": {
      "scheduledDelayMillis": 5000,
      "maxExportBatchSize": 200,
      "maxQueueSize": 8192
    },
    "tengu_mcp_tool_search": false,
    "tengu_scratch": false,
    "tengu_log_segment_events": false,
    "tengu_log_datadog_events": true,
    "tengu_event_sampling_config": {},
    "tengu_tool_pear": false,
    "tengu_thinkback": false,
    "tengu_sumi": false
  },
  "userID": "xxx",
  "firstStartTime": "2026-01-12T12:59:53.117Z",
  "sonnet45MigrationComplete": true,
  "opus45MigrationComplete": true,
  "thinkingMigrationComplete": true,
  "changelogLastFetched": 1768222793309,
  "autoUpdatesProtectedForNative": true,
  "hasCompletedOnboarding": true
}
```

Uložte soubor a ukončete editor.

##### 4. Spusťte Claude standardně

Spusťte Claude znovu:

```bash
claude
```

Claude by se nyní měl spustit bez spuštění průvodce nastavením a fungovat plynule.

### Konfigurace

Claude Code se konfiguruje pomocí proměnných prostředí. Exportujte následující proměnné ve svém shellu:

```bash
export ANTHROPIC_BASE_URL="https://llm.ai.e-infra.cz/"
export ANTHROPIC_AUTH_TOKEN="sk-..."
export ANTHROPIC_MODEL="glm-4.7"
export ANTHROPIC_DEFAULT_OPUS_MODEL="glm-4.7"
export ANTHROPIC_DEFAULT_SONNET_MODEL="glm-4.7"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="gpt-oss-120b"
export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
```

Alternativně můžete tyto proměnné prostředí definovat v souboru nastavení `~/.claude/settings.json`:

```json title="settings.json"
{
  "permissions": {
    "defaultMode": "acceptEdits"
  },
  "env": {
    "ANTHROPIC_BASE_URL": "https://llm.ai.e-infra.cz/",
    "ANTHROPIC_AUTH_TOKEN": "sk-...",
    "ANTHROPIC_MODEL": "glm-4.7",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "glm-4.7",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "glm-4.7",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "gpt-oss-120b",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  }
}
```

**Popis proměnných::**

- `ANTHROPIC_BASE_URL` – Základní URL naší LLM API.
- `ANTHROPIC_AUTH_TOKEN` – Váš API token získaný z [https://chat.ai.e-infra.cz](https://chat.ai.e-infra.cz).
- `ANTHROPIC_MODEL` – Výchozí model používaný při spuštění Claude Code.
- `ANTHROPIC_DEFAULT_OPUS_MODEL` – Výchozí model používaný pro odvozování a složité úkoly v Claude Code.
- `ANTHROPIC_DEFAULT_SONNET_MODEL` – Výchozí model používaný pro odvozování a méně složité úkoly v Claude Code.
- `ANTHROPIC_DEFAULT_HAIKU_MODEL` – Výchozí model používaný pro jednoduché úkoly.
- `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` – Zakáže odesílání telemetrie a různého reportingu (nepoužívá se s ne-anthropics API).

### Spuštění Claude Code

Jakmile jsou proměnné prostředí nastavené, spusťte Claude Code pomocí:

```bash
claude [project-dir]
```

Nyní byste měli být schopni pracovat s Claude Code pomocí našeho backendu a zvoleného modelu.

<Callout type="idea">
Můžete si zvolit kterýkoliv z našich dostupných modelů, např.  `qwen3-coder`. Ne všechny modely ale zaručeně fungují správně s Claude Code.
</Callout>

<Callout type="warn">
Pokud Claude Code přestane reagovat nebo se neočekávaně ukončí, nejčastější příčinou je překročení velikosti kontextu modelu. Chcete-li problém vyřešit, přepněte na jiný model s větším kontextovým oknem nebo zmenšete množství textu zpracovávaného najednou.
</Callout>

## Codex

Můžete nasadit [Codex](https://github.com/openai/codex?tab=readme-ov-file) a nakonfigurovat jej tak, aby pracoval s našimi modely tím, že jej nasměrujete na náš API endpoint.

### Instalace

Nejprve nainstalujte Codex pro váš operační systém podle oficiálních pokynů v upstream repozitáři:

- [Codex – Instalace a spuštění Codex CLI](https://github.com/openai/codex?tab=readme-ov-file#installing-and-running-codex-cli)

Ujistěte se, že CLI `codex` je po instalaci k dispozici ve vašem `$PATH`.

<Callout type="idea">
Pro Linux nebo Windows se doporučuje navštívit stránku [Releases](https://github.com/openai/codex/releases) a stáhnout si vhodný předkompilovaný binární soubor pro vaši platformu.
</Callout>

### Konfigurace

Nastavte proměnné prostředí:

```bash
export OPENAI_BASE_URL=https://llm.ai.e-infra.cz
export OPENAI_API_KEY=sk-...
```

Nahraďte `sk-...` svým API klíčem získaným z: https://chat.ai.e-infra.cz

Aplikaci spusťte následujícím příkazem:

```bash
codex --model qwen3-coder --full-auto
```

Po vyzvání k přihlášení:  
1. Vyberte **Provide your own API key**.  
2. Potvrďte **Use your own OpenAI API key for usage-based billing**.  

Po dokončení tohoto kroku je nastavení hotové a aplikace připravená k použití.

## Open Code

Můžete nasadit [Open Code](https://github.com/anomalyco/opencode)  a nakonfigurovat jej tak, aby pracoval s našimi modely tím, že jej nasměrujete na náš API endpoint.


### Instalace

Nejprve nainstalujte Open Code pro váš operační systém podle oficiálních pokynů v upstream repozitáři:

- [Open Code – Instalace](https://github.com/anomalyco/opencode?tab=readme-ov-file#installation)

Ujistěte se, že CLI `opencode je po instalaci k dispozici ve vašem `$PATH`.

### Konfigurace

1. Uložte následující konfiguraci do souboru `~/.config/opencode/opencode.json`:

```json title="~/.config/opencode/opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "litellm": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "LiteLLM",
      "options": {
        "baseURL": "https://llm.ai.e-infra.cz/v1"
      },
      "models": {
        "deepseek-r1": {
          "name": "deepseek-r1"
        },
        "gpt-oss-120b": {
          "name": "gpt-oss-120b"
        },
        "qwen3-coder": {
          "name": "qwen3-coder"
        },
        "glm-4.7": {
          "name": "glm-4.7"
        }
      }
    }
  }
}
```

2. Spusťte aplikaci příkazem:
   ```bash
   opencode
   ```

3. V prostředí `opencode` zadejte:
   ```
   /connect
   ```

4. Ze seznamu dostupných poskytovatelů sjeďte na konec a vyberte **LiteLLM**.

5. Po výzvě vložte svůj API klíč získaný z: https://chat.ai.e-infra.cz

6. Vyberte model:
   ```
   qwen3-coder
   ```

Po dokončení je nastavení připraveno k použití.

<Callout type="info">
- Model `gpt-oss-120b` má **částečnou podporu** a nemusí fungovat podle očekávání.
- Model `qwen3-coder` by měl fungovat stejně dobře jako `glm-4.7`.
</Callout>

## Visual Studio Code

AI chatbota lze integrovat do Visual Studio Code. K tomu lze využít rozšíření třetích stran, například [Continue](https://marketplace.visualstudio.com/items?itemName=Continue.continue) nebo [Roo Code](https://marketplace.visualstudio.com/items?itemName=RooCode.roocode). Tato rozšíření umožňují využít AI v různých rolích, které vám pomohou při programování ve Visual Studio Code. Role zahrnují jednoduchý chat, agentní režim nebo automatické doplňování kódu. Chat poskytuje známou konverzační zkušenost, agentní režim umožňuje analyzovat nebo upravovat soubory otevřené ve vašem projektu a role automatického doplňování navrhuje kód při jeho psaní.

### Instalace rozšíření Continue

Když je Visual Studio Code spuštěné, otevřete kartu Extensions  (`Ctrl+Shift+X`) a vyhledejte `Continue`.  Klikněte na rozšíření a poté na tlačítko `Install`. Po dokončení instalace můžete k rozšíření `Continue` řistupovat kliknutím na ikonu `Continue` v levém postranním panelu.


### Konfigurace rozšíření Continue

Nejprve je třeba upravit konfigurační soubor  `config.yaml`. K rozšíření `Continue` ve Visual Studio Code se dostanete kliknutím na jeho ikonu v levém postranním panelu.

1. Klikněte na  `Open settings`  v pravém horním rohu okna rozšíření `Continue`.
2. Klikněte na `Configs`.
3. Klikněte na ikonu `Open configuration` na konci řádku `Local Config`.
4. Jakmile se otevře soubor `config.yaml` použijte následující konfiguraci se svým vlastním `<api-key>` (návod výše):


```
%YAML 1.1
---
name: Local Assistant
version: 1.0.0
schema: v1
model_defaults: &model_defaults
  provider: openai
  apiKey: <api-key>
  apiBase: https://llm.ai.e-infra.cz/v1
models:
  - name: autocomplete-coder
    <<: *model_defaults
    model: qwen3-coder
    promptTemplates:
      autocomplete: '<|fim_prefix|>{{{ prefix }}}<|fim_suffix|>{{{ suffix }}}<|fim_middle|>'
    autocompleteOptions:
      transform: false
    defaultCompletionOptions:
      temperature: 0.6
      maxTokens: 512
    roles:
      - autocomplete
  - name: chat-coder    
    <<: *model_defaults
    model: qwen3-coder
    env:
      useLegacyCompletionsEndpoint: false
    roles:
      - chat
      - edit
context:
  - provider: code
  - provider: docs
  - provider: diff
  - provider: terminal
  - provider: problems
  - provider: folder
  - provider: codebase
```
5. Uložte soubor. Nová konfigurace by se měla použít okamžitě.
6. Zkontrolujte, že je pro automatické doplňování použit režim `FIM` , tím že se podíváte na tlačítko  `Continue` ve stavovém řádku Visual Studio Code (v pravém dolním rohu). Mělo by zobrazovat `Continue`. Nemělo by zobrazovat `Continue (NE)`. Pokud se zobrazí `Continue (NE)`, klikněte na tlačítko a vyberte možnost `Use FIM autocomplete over Next Edit`.

### Použití AI ve Visual Studio Code

* Chat lze otevřít stisknutím ikony `Continue` v levém postranním panelu.
* V chatu můžete zapnout režim agenta tím, že požádáte o analýzu, vysvětlení nebo úpravu souboru v aktuálně otevřeném projektu. Tato akce vyžaduje dodatečná oprávnění, například práva pro čtení/zápis do souvisejících souborů. Musíte udělit potřebná oprávnění, aby agent mohl úkol provést.
* Funkce automatického doplňování bude při psaní průběžně nabízet nové návrhy kódu. Jakmile se návrh zobrazí, přijmete jej stisknutím klávesy `Tab`. Rychlost odezvy návrhů závisí na výkonu modelu. V konfiguraci autocomplete můžete změnit model `qwen3-coder` na `gpt-oss-120b`, který může být o něco rychlejší, ale výchozí model má lepší výsledky při programovacích úlohách.

### Roo Code
[Roo Code](https://marketplace.visualstudio.com/items?itemName=RooVeterinaryInc.roo-cline) je rozšíření pro Visual Studio Code, které poskytuje asistenci AI s vylepšenými schopnostmi agenta a porozuměním kódu.

#### Instalace rozšíření Roo Code
Se spuštěným Visual Studio Code:
1. Otevřete kartu Rozšíření (`Ctrl+Shift+X`)
2. Vyhledejte `Roo Code`
3. Vyberte rozšíření a klikněte na `Install`
4. Po instalaci získáte přístup k Roo Code pomocí jeho ikony v levém postranním panelu



#### Nakonfigurujte rozšíření Roo Code
Chcete-li používat self-hosted modely:
1. Otevřete Roo Code pomocí ikony v postranním panelu
2. Klikněte na ikonu ⚙️ **Settings** (vpravo nahoře)
3. V sekci **Providers**:
   - **API Provider**: `OpenAI Compatible`
   - **Base URL**: `https://llm.ai.e-infra.cz/v1`
   - **API Key**: Váš klíč z [AI Chat WebUI](../ai-as-a-service/chat-ai)
   - **Model**: `qwen3-coder` (nebo alternativní)
4. Nastavte **Context Window Size** podle [této tabulky](../ai-as-a-service/chat-ai#guaranteed-models)
5. Uložte nastavení

#### Používání Roo Code
- Vyberte agenty pomocí tlačítka v levém dolním rohu rozšíření
- Po odeslání zadání agenti pracují autonomně, dokud není potřeba zásah
- Pro pokročilé použití si prostudujte [Roo Code dokumentaci](https://docs.roocode.com/)

#### Codebase indexování

Indexování codebase pomocí jednoho z našich [embedding modelů](../ai-as-a-service/chat-ai#embedding-models) pomáhá agentům lépe vyhledávat a porozumět vaší codebase.
Pro uložení indexu je potřeba nastavit lokální databázi Qdrant. Zde je příklad souboru `docker-compose.yaml`:

```
services:
  qdrant:
    image: qdrant/qdrant
    ports:
      - "6333:6333"
    volumes:
      - qdrant_storage:/qdrant/storage
volumes:
  qdrant_storage:
```

Pro nastavení indexování codebase postupujte podle těchto kroků:

1. Spusťte novou instanci databáze příkazem `docker compose up -d` ve stejném adresáři, kde je uložen poskytnutý soubor `docker-compose.yaml`.
2. V rozhraní rozšíření Roo Code klikněte na ikonu databáze v pravém dolním rohu.
3. Otevřete sekci `Setup`.
4. Nastavte následující hodnoty:
   - **Embedder Provider**: `OpenAI Compatible`
   - **Base URL**: `https://llm.ai.e-infra.cz/v1`
   - **API Key**: Váš API klíč z [AI Chat WebUI](../ai-as-a-service/chat-ai)
   - **Model**: Model: Jeden z našich  [embedding modelů](https://docs.cerit.io/en/docs/ai-as-a-service/chat-ai#embedding-models) např. `qwen3-embedding-4b`
   - **Model Dimension**: The embedding vector size of the selected model e.g. `2560` for `qwen3-embedding-4b`.
   - **Qdrant URL**: `http://localhost:6333`
   - **Qdrant API Key**: Ponechte prázdné, pokud byl použit poskytnutý docker compose.
5. Vytvořte index kliknutím na `Start Indexing`.
6. Po dokončení indexování budou mít agenti přístup k databázi a budou schopni lépe vyhledávat a porozumět codebase.
