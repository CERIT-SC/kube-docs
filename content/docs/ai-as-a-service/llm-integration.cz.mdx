## Úvod

Infrastruktura AI CERIT-SC zpřístupňuje velké jazykové modely (LLM) prostřednictvím standardních API protokolů, což vám umožňuje integrovat výkonnou AI asistenci přímo do vašeho lokálního vývojového prostředí. Připojením vašich nástrojů k našemu backendu můžete využívat vysoce výkonné modely (jako `qwen3-coder` nebo `gpt-oss-120b`) pro programovací úlohy bez nutnosti jejich běhu na vašem vlastním hardwaru nebo závislosti na externích komerčních poskytovatelích.

Tento průvodce vysvětluje, jak nakonfigurovat několik oblíbených nástrojů pro komunikaci s naším API.

<Callout type="info">
Předpoklad: Před pokračováním se ujistěte, že jste vygenerovali API klíč z [AI Chat WebUI](../ai-as-a-service/chat-ai). Tento klíč budete potřebovat pro autentizaci vašeho klienta.
</Callout>

## Claude Code

<Callout type="info">
Claude Code je také integrován do [Jupyter Notebook](../web-apps/jupyterhub#claude-code-integration-in-jupyter-notebook).
</Callout>

[Claude Code](https://github.com/anthropics/claude-code) může být nasazen a nakonfigurován pro práci s našimi modely nasměrováním na náš API koncový bod.

### Instalace

Nainstalujte Claude Code pro váš operační systém podle oficiálních instrukcí v upstream repozitáři:

- [Claude Code – Začínáme](https://github.com/anthropics/claude-code?tab=readme-ov-file#get-started)

Po instalaci se ujistěte, že je `claude` CLI dostupný ve vašem `$PATH`.

#### Instalace pro Linux (včetně Windows WSL)

Tyto instrukce platí jak pro nativní Linux, tak pro Windows Subsystem for Linux (WSL).

##### 1. Nainstalujte Claude Code

Použijte oficiální instalační skript pro instalaci Claude Code:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Po úspěšném dokončení instalace byste měli vidět výstup podobný následujícímu:

```
Setting up Claude Code...

✔ Claude Code successfully installed!

  Version: 2.1.5
  Location: ~/.local/bin/claude

  Next: Run claude --help to get started

✅ Installation complete!
```

##### 2. Spusťte Claude a ukončete během onboarding procesu

Spusťte Claude poprvé:

```bash
claude
```

- Pokračujte výběrem barevného schématu.
- Když se dostanete na obrazovku **"Select login method"**, ukončete aplikaci stisknutím **Ctrl+C** třikrát.

Tento krok vygeneruje počáteční konfigurační soubor bez dokončení onboarding procesu.

##### 3. Ručně dokončete onboarding proces

Otevřete konfigurační soubor Claude:

```bash
vim ~/.claude.json
```

Na **konci souboru** přidejte následující vlastnost:

```json
"hasCompletedOnboarding": true
```

<Callout type="warn">
- Ujistěte se, že předchozí poslední vlastnost končí čárkou.
- JSON musí zůstat platný.
</Callout>

Příklad správně aktualizovaného souboru `~/.claude.json`:

```json
{
  "installMethod": "native",
  "autoUpdates": false,
  "cachedGrowthBookFeatures": {
    "tengu_1p_event_batch_config": {
      "scheduledDelayMillis": 5000,
      "maxExportBatchSize": 200,
      "maxQueueSize": 8192
    },
    "tengu_mcp_tool_search": false,
    "tengu_scratch": false,
    "tengu_log_segment_events": false,
    "tengu_log_datadog_events": true,
    "tengu_event_sampling_config": {},
    "tengu_tool_pear": false,
    "tengu_thinkback": false,
    "tengu_sumi": false
  },
  "userID": "xxx",
  "firstStartTime": "2026-01-12T12:59:53.117Z",
  "sonnet45MigrationComplete": true,
  "opus45MigrationComplete": true,
  "thinkingMigrationComplete": true,
  "changelogLastFetched": 1768222793309,
  "autoUpdatesProtectedForNative": true,
  "hasCompletedOnboarding": true
}
```

Uložte soubor a ukončete editor.

##### 4. Spusťte Claude normálně

Spusťte Claude znovu:

```bash
claude
```

Claude by se nyní měl spustit bez spuštění onboarding procesu a běžet hladce.

### Konfigurace

Claude Code je konfigurován pomocí proměnných prostředí. Exportujte následující proměnné ve vašem shellu:

```bash
export ANTHROPIC_BASE_URL="https://llm.ai.e-infra.cz/"
export ANTHROPIC_AUTH_TOKEN="sk-..."
export ANTHROPIC_MODEL="glm-4.7"
export ANTHROPIC_DEFAULT_OPUS_MODEL="glm-4.7"
export ANTHROPIC_DEFAULT_SONNET_MODEL="glm-4.7"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="gpt-oss-120b"
export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
```

Alternativně můžete definovat tyto proměnné prostředí v nastavovacím souboru `~/.claude/settings.json`:

```json title="settings.json"
{
  "permissions": {
    "defaultMode": "acceptEdits"
  },
  "env": {
    "ANTHROPIC_BASE_URL": "https://llm.ai.e-infra.cz/",
    "ANTHROPIC_AUTH_TOKEN": "sk-...",
    "ANTHROPIC_MODEL": "glm-4.7",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "glm-4.7",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "glm-4.7",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "gpt-oss-120b",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  }
}
```

**Popis proměnných:**

- `ANTHROPIC_BASE_URL` – Základní URL našeho LLM API.
- `ANTHROPIC_AUTH_TOKEN` – Váš API klíč získaný z [https://chat.ai.e-infra.cz](https://chat.ai.e-infra.cz).
- `ANTHROPIC_MODEL` – Výchozí model pro použití při spouštění Claude Code.
- `ANTHROPIC_DEFAULT_OPUS_MODEL` – Výchozí model pro použití při spouštění Claude Code pro uvažování a komplexní úlohy.
- `ANTHROPIC_DEFAULT_SONNET_MODEL` – Výchozí model pro použití při spouštění Claude Code pro uvažování a středně komplexní úlohy.
- `ANTHROPIC_DEFAULT_HAIKU_MODEL` – Výchozí model pro použití pro jednoduché úlohy.
- `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` – Zakáže odesílání telemetrie a různých reportů (nepoužívá se s ne-Anthropic API).

### Spouštění Claude Code

Jakmile jsou nastaveny proměnné prostředí, spusťte Claude Code pomocí:

```bash
claude [project-dir]
```

Nyní byste měli být schopni interagovat s Claude Code pomocí našeho backendu a vybraného modelu.

<Callout type="idea">
Můžete si vybrat kterýkoli z našich dostupných modelů (např. `qwen3-coder`). Ne všechny modely však zaručeně fungují správně s Claude Code.
</Callout>

<Callout type="warn">
Pokud Claude Code přestane reagovat nebo neočekávaně ukončí, nejčastější příčinou je překročení velikosti kontextu modelu. Pro vyřešení tohoto problému přepněte na jiný model s větším kontextovým oknem nebo snižte množství textu zpracovávaného najednou.
</Callout>

## Codex

[Codex](https://github.com/openai/codex?tab=readme-ov-file) může být nasazen a nakonfigurován pro práci s našimi modely nasměrováním na náš API koncový bod.

### Instalace

Nainstalujte Codex pro váš operační systém podle oficiálních instrukcí v upstream repozitáři:

- [Codex – Instalace a spouštění Codex CLI](https://github.com/openai/codex?tab=readme-ov-file#installing-and-running-codex-cli)

Po instalaci se ujistěte, že je `codex` CLI dostupný ve vašem `$PATH`.

<Callout type="idea">
Pro Linux nebo Windows se doporučuje navštívit stránku [Releases](https://github.com/openai/codex/releases) a stáhnout vhodný předkompilovaný binární soubor pro vaši platformu.
</Callout>

### Konfigurace

Nastavte tyto proměnné prostředí:

```bash
export OPENAI_BASE_URL=https://llm.ai.e-infra.cz
export OPENAI_API_KEY=sk-...
```

Nahraďte `sk-...` svým API klíčem získaným z: https://chat.ai.e-infra.cz

Spusťte aplikaci následujícím příkazem:

```bash
codex --model qwen3-coder --full-auto
```

Po zobrazení výzvy k přihlášení:
1. Vyberte **Provide your own API key**.
2. Potvrďte **Use your own OpenAI API key for usage-based billing**.

Poté je nastavení dokončeno a připraveno k použití.

## Open Code

[Open Code](https://github.com/anomalyco/opencode) může být nasazen a nakonfigurován pro práci s našimi modely nasměrováním na náš API koncový bod.

### Instalace

Nainstalujte Open Code pro váš operační systém podle oficiálních instrukcí v upstream repozitáři:

- [Open Code – Instalace](https://github.com/anomalyco/opencode?tab=readme-ov-file#installation)

Po instalaci se ujistěte, že je `opencode` CLI dostupný ve vašem `$PATH`.

### Konfigurace

1. Uložte následující konfiguraci do souboru `~/.config/opencode/opencode.json`:

```json title="~/.config/opencode/opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "litellm": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "LiteLLM",
      "options": {
        "baseURL": "https://llm.ai.e-infra.cz/v1"
      },
      "models": {
        "deepseek-r1": {
          "name": "deepseek-r1"
        },
        "gpt-oss-120b": {
          "name": "gpt-oss-120b"
        },
        "qwen3-coder": {
          "name": "qwen3-coder"
        },
        "glm-4.7": {
          "name": "glm-4.7"
        }
      }
    }
  }
}
```

2. Spusťte aplikaci příkazem:
   ```bash
   opencode
   ```

3. Uvnitř `opencode` napište:
   ```
   /connect
   ```

4. Ze seznamu dostupných poskytovatelů přejděte na konec a vyberte **LiteLLM**.

5. Po zobrazení výzvy vložte svůj API klíč získaný z: https://chat.ai.e-infra.cz

6. Vyberte model:
   ```
   glm-4.7
   ```

Po dokončení je nastavení připraveno k použití.

<Callout type="info">
- Model `gpt-oss-120b` má **částečnou podporu** a nemusí fungovat podle očekávání.
- Model `qwen3-coder` by měl fungovat stejně dobře jako `glm-4.7`.
</Callout>

## Visual Studio Code

Integrujte AI chatbota do Visual Studio Code pomocí rozšíření třetích stran, jako je [Continue](https://marketplace.visualstudio.com/items?itemName=Continue.continue) nebo [Roo Code](https://marketplace.visualstudio.com/items?itemName=RooCode.roocode). Tato rozšíření umožňují AI asistenci v různých rolích při programování, včetně jednoduchého chatu, agentního režimu a automatického dokončování. Chat poskytuje známé konverzační rozhraní, agentní režim analyzuje nebo upravuje soubory ve vašem projektu a automatické dokončování navrhuje kód při psaní.

### Instalace rozšíření Continue

Při běžícím Visual Studio Code:
1. Otevřete záložku Rozšíření (`Ctrl+Shift+X`) a vyhledejte `Continue`
2. Klikněte na rozšíření a poté klikněte na `Install`
3. Po instalaci přistupujte k rozšíření Continue kliknutím na ikonu Continue v levém postranním panelu

### Konfigurace rozšíření Continue

Nakonfigurujte rozšíření Continue úpravou souboru `config.yaml`:

1. Přejděte do rozšíření Continue v rámci Visual Studio Code pomocí ikony v levém postranním panelu

1. Klikněte na `Open settings` v pravém horním rohu okna rozšíření `Continue`.
2. Klikněte na `Configs`.
3. Klikněte na ikonu `Open configuration` na konci řádku označeného `Local Config`.
4. Po otevření `config.yaml` použijte následující konfiguraci s vaším vlastním `<api-key>` (návod výše):

```yaml
%YAML 1.1
---
name: Local Assistant
version: 1.0.0
schema: v1
model_defaults: &model_defaults
  provider: openai
  apiKey: <api-key>
  apiBase: https://llm.ai.e-infra.cz/v1
models:
  - name: autocomplete-coder
    <<: *model_defaults
    model: qwen3-coder
    promptTemplates:
      autocomplete: '<|fim_prefix|>{{{ prefix }}}<|fim_suffix|>{{{ suffix }}}<|fim_middle|>'
    autocompleteOptions:
      transform: false
    defaultCompletionOptions:
      temperature: 0.6
      maxTokens: 512
    roles:
      - autocomplete
  - name: chat-coder
    <<: *model_defaults
    model: qwen3-coder
    env:
      useLegacyCompletionsEndpoint: false
    roles:
      - chat
      - edit
context:
  - provider: code
  - provider: docs
  - provider: diff
  - provider: terminal
  - provider: problems
  - provider: folder
  - provider: codebase
```

5. Uložte soubor. Nová konfigurace by se měla okamžitě aplikovat.
6. Ověřte, že se používá `FIM` automatické dokončování kontrolou tlačítka `Continue` v řádku stavu Visual Studio Code (pravý dolní roh). Měl by zobrazovat `Continue`, nikoli `Continue (NE)`. Pokud se zobrazuje `Continue (NE)`, klikněte na toto tlačítko a vyberte `Use FIM autocomplete over Next Edit`.

### Používání AI v Visual Studio Code

* **Chat**: Přejděte do chatu kliknutím na ikonu Continue v levém postranním panelu
* **Agentní režim**: V chatu aktivujte agentní režim požádáním o analýzu, vysvětlení nebo úpravu souborů ve vašem aktuálním projektu. To vyžaduje další oprávnění, jako je přístup pro čtení/zápís k souvisejícím souborům; musíte tato oprávnění udělit, aby agent mohl provádět požadované akce
* **Automatické dokončování**: Funkce automatického dokončování průběžně navrhuje nový kód při psaní. Stiskněte `Tab` pro přijetí návrhů. Reaktivita závisí na rychlosti modelu. Model můžete změnit z `qwen3-coder` na `gpt-oss-120b` v sekci konfigurace automatického dokončování pro rychlejší odpovědi, i když výchozí model obecně lépe plní programovací úlohy

### Roo Code

[Roo Code](https://marketplace.visualstudio.com/items?itemName=RooVeterinaryInc.roo-cline) je rozšíření Visual Studio Code nabízející AI asistenci s vylepšenými schopnostmi agentů a porozumění kódu.

#### Instalace rozšíření Roo Code

Při běžícím Visual Studio Code:
1. Otevřete záložku Rozšíření (`Ctrl+Shift+X`)
2. Vyhledejte `Roo Code`
3. Vyberte rozšíření a klikněte na `Install`
4. Po instalaci přistupujte k Roo Code prostřednictvím jeho ikony v levém postranním panelu

#### Konfigurace rozšíření Roo Code

Pro použití vlastních hostovaných modelů:
1. Otevřete Roo Code pomocí ikony v postranním panelu
2. Klikněte na ikonu ⚙️ **Settings** (pravý horní roh)
3. V sekci **Providers**:
   - **API Provider**: `OpenAI Compatible`
   - **Base URL**: `https://llm.ai.e-infra.cz/v1`
   - **API Key**: Váš klíč z [AI Chat WebUI](../ai-as-a-service/chat-ai)
   - **Model**: `qwen3-coder` (nebo alternativní)
4. Nastavte **Context Window Size** pomocí [této tabulky](../ai-as-a-service/chat-ai#garantované-modely)
5. Uložte nastavení

#### Používání Roo Code

- Vyberte agenty pomocí tlačítka v levém dolním rohu rozšíření
- Po odeslání promptu pracují agenti autonomně, dokud není potřeba zásah
- Pro pokročilé použití se podívejte do [dokumentace Roo Code](https://docs.roocode.com/)

#### Indexování kódové báze

Indexujte kódovou bázi pomocí jednoho z našich [embedding modelů](../ai-as-a-service/chat-ai#embedding-modely), aby agenti mohli lépe prohledávat a rozumět vaší kódové bázi.
Pro uložení indexu nastavte lokální databázi Qdrant. Zde je příklad `docker-compose.yaml`:

```yaml
services:
  qdrant:
    image: qdrant/qdrant
    ports:
      - "6333:6333"
    volumes:
      - qdrant_storage:/qdrant/storage
volumes:
  qdrant_storage:
```

Nakonfigurujte indexování kódové báze podle těchto kroků:

1. Spusťte novou instanci databáze spuštěním `docker compose up -d` v adresáři obsahujícím soubor `docker-compose.yaml`
2. V rozhraní rozšíření Roo Code klikněte na ikonu databáze v pravém dolním rohu.
3. Otevřete sekci `Setup`.
4. Nastavte následující hodnoty:
   - **Embedder Provider**: `OpenAI Compatible`
   - **Base URL**: `https://llm.ai.e-infra.cz/v1`
   - **API Key**: Váš API klíč z [AI Chat WebUI](../ai-as-a-service/chat-ai)
   - **Model**: Jeden z našich [embedding modelů](../ai-as-a-service/chat-ai#embedding-modely), např. `qwen3-embedding-4b`
   - **Model Dimension**: Velikost vektoru embeddingu vybraného modelu, např. `2560` pro `qwen3-embedding-4b`.
   - **Qdrant URL**: `http://localhost:6333`
   - **Qdrant API Key**: Ponechte prázdné, pokud jste použili poskytnutou Docker Compose konfiguraci.
5. Vytvořte index kliknutím na `Start Indexing`.
6. Po dokončení indexování budou mít agenti přístup k databázi a budou moci lépe prohledávat a rozumět kódové bázi.
