## Currently available models

Check the [live status page](https://llm.ai.e-infra.cz/status/)
for current availability. The tables below describe the documented
model inventory; deployments and settings may change.

-> [Complete list of models (API)](./ai-api#listing-available-models)

<Callout type="info">
For exact, currently served model names, query the live model list via the API (see [Creating an API Key](#creating-an-api-key)) or check the [status page](https://llm.ai.e-infra.cz/status/). When accessing externally you must use either a maintained alias or the exact model name, e.g. `qwen3.8-27b` or `deepseek-v4.1-flash`.

Model names are case-sensitive and may include a quantization suffix.
</Callout>

For programmatic access, use a maintained
[model alias](#model-aliases) or an exact model identifier returned
by the API. Model identifiers are case-sensitive.

- **Kimi K3.1-pro** — New Moonshot AI's open-weight 2.8T-parameter Mixture-of-Experts (MoE) flagship model. Native multimodal with vision support, a 1M-token context window, and strong performance in long-horizon coding, reasoning, knowledge work, and agentic workflows.
- **GLM 5.3** — 756B-parameter language model optimized for advanced reasoning, tool use, and multi-step agentic tasks.
- **GLM 5.3 Flash** — 320B-parameter (18B active) Mixture-of-Experts multimodal model from ZAI for reasoning, coding, and agentic tasks. The NVIDIA NVFP4 build reduces weight memory by about 3.3 times compared with BF16 and keeps benchmark accuracy close to the BF16 baseline.
- **GPT-OSS-120B** — OpenAI's 120B-parameter open-weight language model offering strong general-purpose performance across reasoning, coding, and tool use.
- **DeepSeek V4.1 Flash-1017** — efficient reasoning model with a small activated parameter count relative to leading proprietary models. Excels at mathematics, logical reasoning, and code generation.
- **Qwen3.8 Flash Next** — 180B (MoE) multimodal model with improved coding performance. fp8 quantization, 256k context, and a maximum output of 48k tokens.
- **Qwen3.8 27B** — 27B (dense) multimodal model with significantly improved coding performance. Supports images and videos, with configurable thinking for balancing speed and reasoning.
- **Mistral Medium 3.5** — 128B multimodal model for text, coding, tool use, and agentic workflows.
- **Gemma 4** — Google's 31B multimodal model; useful for OCR/vision and general-purpose tasks.
- **Whisper Large v3** — OpenAI's 1.55B automatic speech recognition (ASR) and speech-translation model; supports 99+ languages with robust transcription even in noisy conditions. Available via API only.  See its
[model card](https://huggingface.co/openai/whisper-large-v3)
for background information. It is not a text-chat model.
- **Canary 1B v2**: Multitask Speech Transcription and Translation Model
Canary-v2 is a powerful 1-billion parameter model built for high-quality speech transcription and translation across 25 European languages. It excels at both automatic speech recognition (ASR) and speech translation (AST).


### Model aliases

An alias is a maintained name that points to a deployed model.
Its target can change when the service is updated.

Aliases reduce the need to change model names in scripts, but they
do not guarantee identical behaviour, outputs, or uninterrupted access.

| Alias | Documented target | Notes |
| --- | --- | --- |
| `glm` | `glm-5.3` | Maintained GLM alias |
| `glm-5` | `glm-5.3` | Legacy alias; use `glm` for new configurations |
| `kimi` | `kimi-k3.1-pro` | Maintained Kimi alias |
| `deepseek` | `deepseek-v4.1-flash` | Reasoning disabled by default |
| `deepseek-thinking` | `deepseek-v4.1-flash-thinking` | Reasoning enabled |
| `thinker` | `deepseek-v4.1-flash-thinking` | Reasoning alias |
| `mini` | `gpt-oss-120b` | General-purpose alias |
| `coder`, `agentic` | `qwen3.8-flash-next` | Coding and agent-workflow aliases |

The documented `deepseek` and `deepseek-thinking` targets use the
same underlying model weights with different reasoning defaults.

Use an exact model identifier when you need to record which version
was used. An exact identifier does not reserve that version or
guarantee its future availability.

### Embedding models

Embedding models represent text as numerical vectors for semantic
search and document retrieval. Rerankers perform a different task:
they reorder candidate results according to their relevance to a query.

These services are accessed programmatically. See the
[API guide](./ai-api) for access and supported requests.

| Model identifier | Type | Documented input limit | Embedding dimensions |
| --- | --- | --- | --- |
| `qwen3-embedding-4b` | Embedding | 40,960 tokens | 2,560 |
| `qwen3-reranker-4b` | Reranker | 40,960 tokens | Not applicable |
| `nomic-embed-text-v1.5` | Embedding | 512 tokens | 768 |
| `nomic-embed-text-v2-moe` | Embedding | 512 tokens | 768 |
| `mxbai-embed-large:latest` | Embedding | 512 tokens | 1,024 |

Check the deployed configuration before designing a document-processing
pipeline. Input limits, supported languages, and preprocessing
requirements should be evaluated for your dataset.
