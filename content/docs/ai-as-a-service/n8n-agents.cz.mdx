## Úvod

n8n je open-source low-code platforma pro workflow automatizaci. Používá vizuální, node-based systém pro propojení více než 400 aplikací a API.

Jeho funkce AI agenta umožňuje uživatelům vytvářet autonomní workflows poháněné velkými jazykovými modely (LLM), které mohou činit rozhodnutí, komunikovat s aplikacemi a provádět složité, vícestupňové úkoly bez neustálého lidského zásahu.

Zatímco standardní n8n workflows sledují lineární postup (Trigger → Action → Action), funkce AI agenta zavádí autonomii.



### Co je AI agent?

<div class="w-150">  
![image-agents2](/img/ceritsc/agent.jpeg)  
</div> 

V n8n je AI agent vytvářen vizuálně. Uzel AI Agent se nachází uprostřed a funguje jako řídicí prvek. Připojujete „Mozek“ (LLM model), „Nástroje“ (Tools) a „Paměť“ (Memory) přímo ke vstupům uzlu agenta. Workflow obvykle začíná Triggerem, například Chat Triggerem nebo Webhookem.


Místo dodržování pevně definované sady kroků používá agent velký jazykový model (LLM) k tomu, aby:

- porozuměl vstupu v přirozeném jazyce,
- uvažoval o nejlepším způsobu řešení problému,
- vybíral nástroje (Tools) (například vyhledávání, dotazy do databáze nebo API volání) pro získání informací,
- vykonával komplexní, vícekrokové úlohy bez neustálého zásahu člověka.

## Jak vytvořit agenta

**Krok 1: Trigger**

Pro interakci s vaším agentem potřebujete trigger. Pro testování a vytváření chatbotů je standardním výchozím bodem **Chat Trigger**.

<Callout type="info">
Pro backendovou automatizaci (např. zpracování e-mailů) byste místo toho použili Webhook nebo Email Trigger.
</Callout>

**Krok 2: Připojení „mozku“**

Připojte uzel Chat Model (např. OpenAI) ke vstupu "Model" uzlu agenta. [K našim lokálnym modelom je možné pristupovať](./chat-ai#creating-an-api-key) pomocou tokenu vygenerovaného v predchádzajúcej kapitole.

* Přihlašovací údaje: Budete potřebovat API klíč od poskytovatele  
* Výběr modelu: Vyberte model schopný uvažování (reasoning)



**Krok 3: Konfigurace agenta**

Uzel **AI Agent** vyžaduje specifickou konfiguraci, aby správně fungoval:

| Nastavení       | Doporučení |
|-----------------|------------|
| Agent Type  | Vyberte `Tools Agent`. Toto je nejvšestrannější typ, který může používat externí nástroje. |
| Prompt Source | Obvykle `Connected Chat Trigger` nebo `Define below`, pokud používáte webhook. |
| System Message | KRITICKÉ. Zde definujete personu. Např.: "You are a helpful math assistant. Always use the calculator tool." |


**Krok 4: Posílení pomocí nástrojů**

Bez nástrojů je LLM jen generátor textu. Nástroje mu dávají schopnosti. Můžete připojit:  

* **Předpřipravené nástroje:** Kalkulačka, Wikipedia, Bing Search  
* **Vlastní nástroje:** Jakýkoli n8n workflow lze převést na nástroj pomocí nástroje **Call Workflow**



**Krok 5: Správa paměti**

**Window Buffer Memory:** Uchovává „posuvné okno“ posledních K zpráv. Nejvhodnější pro: Nízké náklady na tokeny při zachování okamžitého kontextu.

**Simple Memory:** Ukládá celou historii konverzace do paměti RAM během vykonávání. Nejvhodnější pro: Krátké, složité relace, kde záleží na každém detailu.

<Callout type="info">
Bez připojeného uzlu paměti agent považuje každou zprávu za zcela novou konverzaci.
</Callout>

## Příklad: Přidání kalkulačky do OpenAI-powered chat agenta (s našimi lokálními modely)

<div class="w-200">  
![image-api2](/img/ceritsc/n8n-choose-LLM-2.png)  
</div> 

1. Add AI agent 

* Open the Nodes panel → click Add Node → search for AI Agent.  
* Drag the node onto the canvas.

1. Přidejte AI agenta  

* Otevřete panel Nodes → klikněte na Add Node → vyhledejte AI Agent  
* Přetáhněte uzel na plátno

<div class="w-200">  
![image-api](/img/ceritsc/n8n-choose-LLM-1.png)  
</div> 

2. Připojte OpenAI Chat model

<div class="w-200">  
![image-api](/img/ceritsc/n8n-choose-LLM-2a.png)  
</div> 

3. Nakonfigurujte autentizaci pro lokální model

| Pole       | Hodnota                                  | 
|------------|-----------------------------------------|
| API Key | Vložte token, který jste vygenerovali dříve |
| Base URL | https://llm.ai.e-infra.cz/v1           |
| Model  | Vyberte požadovaný model (např. GPT‑OSS‑120b) |

<div class="w-200">  
![image-api](/img/ceritsc/n8n-choose-LLM-3.png)  
</div> 

<div class="w-200">  
![image-api](/img/ceritsc/n8n-choose-LLM-4.png)  
</div> 


4. Přidejte `Chat Trigger`  
Trigger spustí workflow, když uživatel odešle zprávu.  
* Z panelu Nodes přidejte Chat Trigger  
* Připojte jeho výstup ke vstupu uzlu AI Agent

<div class="w-200">  
![image-api](/img/ceritsc/n8n-trigger.png)  
</div> 

5. Podobně přidejte `Simple Memory` a `Calculator`  
* Simple Memory uchovává kontext konverzace, aby model mohl odkazovat na předchozí zprávy.  
* Calculator zpracovává aritmetické požadavky přicházející od LLM.  
Propojte je v tomto pořadí: Chat Trigger → AI Agent → Simple Memory → Calculator → (volitelný) response node.

6. Otestujte workflow

- Otevřete rozhraní **Chat Trigger** (nebo použijte integrovaný testovací panel).  
- Zadejte jednoduchý matematický požadavek, např. „What is 5 × 5?“  
- Workflow by měl požadavek předat kalkulačce, vrátit odpověď a zobrazit ji v chatovacím okně.

<div class="w-200">  
![image-api](/img/ceritsc/n8n-result.png)  
</div>
