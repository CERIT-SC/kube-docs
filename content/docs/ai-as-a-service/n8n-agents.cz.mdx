## Úvod

n8n je open-source platforma pro automatizaci workflow s nízkým kódováním, která používá vizuální, uzlů založený systém pro připojení více než 400 aplikací a API.

Jeho funkce AI Agent umožňuje uživatelům vytvářet autonomní workflow poháněné velkými jazykovými modely (LLM), které mohou rozhodovat, interagovat s aplikacemi a provádět komplexní, vícekrokové úlohy bez neustálého lidského vstupu.

Zatímco standardní workflow n8n následují lineární cestu (Spouštěč → Akce → Akce), funkce AI Agent zavádí autonomii.

### Co je AI agent?

<div class="w-150">
![image-agents2](/img/ceritsc/agent.jpeg)
</div>

V n8n je AI Agent vytvořen vizuálně. Uzel AI Agent se nachází ve středu a působí jako kontrolér. Připojíte "Mozek" (LLM Model), "Nástroje" a "Paměť" přímo ke vstupům agentního uzlu. Workflow obvykle začíná spouštěčem, jako je Chat Trigger nebo Webhook.

Místo následování přísné sady předdefinovaných kroků Agent používá velký jazykový model (LLM) k:

* Porozumění přirozeného jazykového vstupu.
* Uvažování o nejlepším způsobu řešení problému.
* Výběru nástrojů (jako je vyhledávání, prohledávání databází nebo volání API) pro shromažďování informací.
* Provádění komplexních, vícekrokových úloh bez neustálého lidského zásahu.

<Callout type="warn">
⚠️ Upozornění na dostupnost služeb:

Uvědomte si prosím následující omezení infrastruktury:
* Údržba: Základní hardware může vyžadovat periodickou údržbu. V současné době nemáme záložní infrastrukturu srovnatelného rozsahu.

## Jak vytvořit agenta

**Krok 1: Spouštěč**

Pro interakci s vaším agentem potřebujete spouštěč. Pro testování a vytváření chatbotů je Chat Trigger standardním výchozím bodem.

<Callout type="info">
Pro backendovou automatizaci (jako je zpracování e-mailů) použijte místo toho Webhook nebo Email Trigger.
</Callout>

**Krok 2: Připojení mozku**

Připojte uzel Chat Model (např. OpenAI) ke vstupu "Model" uzlu Agent. [K našim lokálním modelům lze přistupovat](./chat-ai#vytvoření-api-klíče) pomocí tokenu vygenerovaného v předchozí kapitole.

* Přihlašovací údaje: Budete potřebovat API klíč od poskytovatele.
* Výběr modelu: Vyberte model schopný uvažování.

**Krok 3: Konfigurace agenta**

Uzel AI Agent vyžaduje specifickou konfiguraci pro správné fungování:

| Nastavení   | Doporučení |
|------------|----------------|
| Typ agenta  | Vyberte `Tools Agent`. Toto je nejuniverzálnější typ, který může používat externí nástroje. |
| Zdroj promptu | Obvykle `Connected Chat Trigger` nebo `Define below` pokud používáte webhook.  |
| Systémová zpráva | KRITICKÉ. Zde definujete personu. Příklad: "Jste užitečný matematický asistent. Vždy používejte nástroj kalkulačka."  |

**Krok 4: Vybavení nástroji**

Bez nástrojů je LLM pouze generátorem textu. Nástroje mu dávají schopnost provádět akce. Můžete připojit:
* **Předpřipravené nástroje**: Kalkulačka, Wikipedia, Bing Search
* **Vlastní nástroje**: Jakékoli workflow n8n může být převedeno na nástroj pomocí nástroje "Call Workflow".

**Krok 5: Správa paměti**

**Paměť s klouzavým oknem**: Uchovává "klouzavé okno" posledních K zpráv. Nejlepší pro: Udržení nízkých nákladů na tokeny při zachování bezprostředního kontextu.

**Jednoduchá paměť**: Ukládá celou historii konverzace v paměti RAM při spuštění. Nejlepší pro: Krátké, komplexní relace, kde záleží na každém detailu.

<Callout type="info">
Bez připojeného uzlu paměti agent považuje každou zprávu za zcela novou konverzaci.
</Callout>

## Příklad: Přidání kalkulačky k OpenAI‑poháněnému chat agentovi (s našimi lokálními modely)

1. **Přidejte AI agenta**
   * Otevřete panel Uzly → klikněte na Add Node → vyhledejte AI Agent.
   * Přetáhněte uzel na plátno.

<div class="w-200">
![image-api](/img/ceritsc/n8n-choose-LLM-1.png)
</div>

2. Připojte OpenAI Chat model

<div class="w-200">
![image-api](/img/ceritsc/n8n-choose-LLM-2a.png)
</div>

3. Nakonfigurujte autentizaci pro lokální model

| Pole | Hodnota                                   |
|--------|----------------------------------------|
| API klíč | Vložte token, který jste dříve vygenerovali |
| Základní URL | https://llm.ai.e-infra.cz/v1         |
| Model | Vyberte požadovaný model (např. GPT‑OSS‑120b)  |

<div class="w-200">
![image-api](/img/ceritsc/n8n-choose-LLM-3.png)
</div>

<div class="w-200">
![image-api](/img/ceritsc/n8n-choose-LLM-4.png)
</div>

4. Přidejte `Chat trigger`

Spouštěč spustí workflow, když uživatel odešle zprávu.
* Z panelu Uzly přidejte Chat Trigger.
* Připojte jeho výstup ke vstupu uzlu AI Agent.

<div class="w-200">
![image-api](/img/ceritsc/n8n-trigger.png)
</div>

5. Podobně přidejte `Simple memory` a `Calculator`

* Simple Memory ukládá kontext konverzace, aby model mohl odkazovat na předchozí zprávy.
* Calculator zpracovává aritmetické požadavky od LLM.
Připojte je v pořadí: Chat Trigger → AI Agent → Simple Memory → Calculator → (volitelně) response node.

6. Otestujte workflow

* Otevřete rozhraní Chat Trigger (nebo použijte integrovaný testovací panel).
* Napište přímý matematický požadavek, např. "Kolik je 5 × 5?".
* Workflow by měl směrovat požadavek na Calculator, vrátit odpověď a zobrazit ji v chatovém okně.

<div class="w-200">
![image-api](/img/ceritsc/n8n-result.png)
</div>
