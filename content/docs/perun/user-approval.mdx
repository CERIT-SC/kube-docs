---
title: Approving User Membership
---

When a user applies for membership in the VO under your administration, you will receive an email similar to the example at the end of this page. The email will contain a link that redirects you to the webpage with detailed information about the requesting user. You click the link to log in to the Perun system, where you can Approve/Reject the user´s application.

To approve/reject the application manually, first log in to the [Perun system](perun.einfra.cesnet.cz/login), then select the virtual organization you wish to manage users applications. Next, click on the **Applications (1)** tile.

![perun](/img/data-care/perun/perun-approve-user1.png)

Then, you will see a list of all submitted applications and their statuses. You can click on the **particular application (1)**, that you wish to accept/reject.

![perun](/img/data-care/perun/perun-approve-user2.png)

Finally, you will see the detailed view of the application, where you can click on the **Approve/Reject (1)** button.

![perun](/img/data-care/perun/perun-approve-user3.png)

An example of the email sent to the VO administrator when a new application is submitted is shown below.

```text
Dear administrator,

New application for VO Test was created by user: Albert, albert@einstein.cz / https://whoami.einstein.cz/idp/shibboleth.

Application detail with all user submitted data where you can approve / reject the application: https://perun.einfra.cesnet.cz/organizations/xyz/applications/1525/?

If there was any error during application creation, information follows:

--------------------------------------------------
Your Perun management team
```
