---
title: Extension of mebership in VO
---

When the user will ask for extending of membership in the VO under your administration, you will receive an email with similar structure like the example in the end of this page. There you can find link, which will redirect you to the web page with detail info about requesting user. Please click on the link and then log in to the Perun system. Now you can Approve/Reject the user application.

If you want to approve/reject the application manually you need to login to [Perun system](perun.einfra.cesnet.cz/login) first and then select the virtual organization where you wish to manage the users applications. Then you need to click on the **Applications (1)** tile.

![perun](/img/data-care/perun/perun-approve-user1.png)

Then you can see the list of all submitted applications and their status. You can click on the **particular application (1)**, that you wish to accept/reject. If you put your cursor on the `Type` field you can see that the application is `Initial` or `Extension`.

![perun](/img/data-care/perun/perun-approve-user2.png)

In the end, you can see the detail view of the application where you can click on the button **Approve/Reject (1)**.

![perun](/img/data-care/perun/perun-approve-user3.png)

<Callout type="warn" icon="⚠️">
All changes made in the Perun system will be active in one hour. **Thus executed changes are not immediate!!!**.
</Callout>


Example of the email being sent to VO administrator when new application has been submitted can be seen below.

```text
Application detail with all user submitted data where you can approve / reject the application: https://perun.einfra.cesnet.cz/organizations/xyz/applications/1525/?

If there was any error during application creation, information follows:

--------------------------------------------------
Your Perun management team
```
