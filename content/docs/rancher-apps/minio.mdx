## Running a Personal MinIO Server

If you are not already logged in, log in to [rancher.cloud.e-infra.cz](https://rancher.cloud.e-infra.cz). See the [Rancher](../rancher/rancher) section for more information.

By following the steps below, you can run a personal MinIO server application. This application is designed to expose or upload data to another running application that uses a persistent volume claim. Data transfer can be done via the web interface (using only a web browser) or via the [S3](https://en.wikipedia.org/wiki/Amazon_S3) protocol (note: this is not related to Amazon AWS; it is their protocol for accessing data).

<Callout type="info">
**Important prerequisite:** The application pod needs to use [PVC](../kubernetes/pvc) for the MinIO server to access data from the pod. If no PVC is used, no data access is possible.

For most applications, it is possible to select *persistent home*, which implies using *PVC*.
</Callout>

### Check Your Application

Select your `Namespace` (1) (remember this `Namespace`; you must select the **same** `Namespace` when installing MinIO below). Navigate through `Workload` (2), `Pods` (3), and the name of the application (4), e.g., `ansys-0`—click on the name. See screenshot below.

![findpod](/img/ceritsc/apps/minio/findpod.png)

Click on the vertical dots (1) and select **Execute Shell** (2).

![enterpod](/img/ceritsc/apps/minio/enterpod.png)

Issue the `df` command in the new *terminal area* (1) and verify that you see a remote file system connected to the home directory (2) or elsewhere.

![inpod](/img/ceritsc/apps/minio/inpod.png)

### Select Application to Run

Ensure you have not selected any namespace and that you see `Only User Namespaces` (1) at the top of the Rancher page.

Navigate through `App & Marketplace` (2), `Charts` (3), limit charts only to `cerit-sc` (4), and select `MinIO` (5). See screenshot below.

![selectapp](/img/ceritsc/apps/minio/selectapp.png)

### Select Version of the Application

When you click on the chart, click `Install` to continue.

![selectversion](/img/ceritsc/apps/minio/selectversion.png)

### Install the Application

Now you can install the MinIO application. In most cases, keep both `Namespace` (1) and `Name` (2) intact; however, you must select the same `Namespace` where the pod for data transfer is running. The `Name` will appear in the URL to access the application. The `Name` must be unique within the `Namespace`; you cannot run two or more instances with the same `Name` in the same `Namespace`.

![appinst](/img/ceritsc/apps/minio/appinst.png)

In the first part of the form, you set the MinIO `username` and `password`. These credentials are used for both web access and S3 access.

![appform](/img/ceritsc/apps/minio/appform1.png)

In the second part of the form, you select the PVC (Persistent Volume Claim), i.e., the persistent volume you want to expose or upload using the MinIO personal server. This should be an existing volume from another application already running in the same `Namespace` that uses *Persistent Home*.

Once you have selected the appropriate PVC, click `Install`.

![appform](/img/ceritsc/apps/minio/appform2.png)

### Wait for Application to Start

When you click `Install`, you will see an installation log. Once you see `SUCCESS` (see screenshot below), the application is running.

![apphelm](/img/ceritsc/apps/minio/apphelm.png)

Once the application is running, navigate through `Service Discovery` (1) and `Ingresses` (2). You will see `Ingresses`. If you see `cm-acme-http-solver...` (3), wait until it disappears. Once you see `minio` or whatever `Name` you used in the previous steps, you can click on Target (4) to log in to the application. There are two targets for MinIO. One Target (4) name begins with the application name (e.g., `minio`); this target is for web access. The second target starts with `s3-` and serves as an S3 API endpoint; this URL is passed to [`s3cmd`](https://s3tools.org/s3cmd) or [`s4cmd`](https://github.com/bloomreach/s4cmd). `Username` and `password` are called **Access key** and **secret key** for the S3 API, and they are the same as those used for web access.

![appacme](/img/ceritsc/apps/minio/appacme.png)

Example usage of `s4cmd` to list data via S3 API:
```bash
s4cmd --access-key=$USER --secret-key=$PASSWORD --endpoint-url=https://s3-minio-nextflow-ns.dyn.cerit-sc.cz ls
```
Replace `$USER`, `$PASSWORD`, and `endpoint-url` with your values.


## Delete a Running Instance

If you no longer need the application, you can delete it. Navigate to `App & Marketplace` (1), `Installed Apps` (2), select the application (3), and click `Delete` (4). The data in the home directory is not deleted if you have persistent home enabled. Running the application again with the same `Name` restores access to the home directory folder.

![appdel](/img/ceritsc/apps/minio/appdel.png)
