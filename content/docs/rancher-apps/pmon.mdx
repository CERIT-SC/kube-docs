---
title: Personal Monitoring
---

Sometimes you want to monitor resource usage of the Pods deployed in your namespaces. The **Personal Monitoring** application allows you to do so in a few easy steps. The application creates a personal Prometheus instance that collects all metrics from your namespace and displays them in a personal Grafana instance at the URL `pmon-[namespace].dyn.cloud.e-infra.cz`.

## Installation

Start by selecting the **Personal Monitoring** application from the Rancher applications menu.

![choose](/img/ceritsc/apps/pmon/choose.png)

After selecting it, click `Install`.

![startinstall](/img/ceritsc/apps/pmon/startinstall.png)

Click `Next`.

<Callout type="warn">
You cannot change the deployed chart name because only one monitoring instance is allowed per namespace.
</Callout>

![next](/img/ceritsc/apps/pmon/next.png)

Change the default credentials used to authenticate to the Grafana instance. Click `Install`.

![install](/img/ceritsc/apps/pmon/install.png)

Wait until the bottom panel shows `SUCCESS` and the installed app shows a green `Deployed` status.

![success](/img/ceritsc/apps/pmon/success.png)

You can now access your monitoring instance at `pmon-[namespace].dyn.cloud.e-infra.cz` or find the final address in the `Ingress` tab.

![ingress](/img/ceritsc/apps/pmon/ingress.png)

After clicking on the link, you are redirected to your Grafana instance. Authenticate with the credentials you entered in the form.

![grafana](/img/ceritsc/apps/pmon/grafana.png)
