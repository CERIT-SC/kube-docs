## Option 1: Running RStudio via JupyterHub (Recommended)

* **Ease of Use:** JupyterHub offers a straightforward way to launch RStudio directly from your Jupyter Notebook environment.
* **Data Integration:** This method provides seamless integration with MetaCentrum home, making it convenient for users already working within this ecosystem.
* **AI Chat Support:** AI integration with the "R 4.* and AI" version
  * RStudio with Claude Code support image: `cerit.io/hubs/rstudio:4.5.2-ai`
* **Supported Versions:** Many RStudio versions are supported through this option.

This is our preferred method due to its simplicity and straightforward setup.
To learn more, see [JupyterHub introduction](../web-apps/jupyterhub), where you can find additional information.


## Option 2: Running RStudio as a Rancher Application

* **Customization:** Offers more customization options, enabling you to tailor the environment to specific needs.
* **Data Integration:** Can be set up to use data from other sources, making it versatile for various data management scenarios.
* **Flexibility in R Versions:** You can choose from multiple R versions, providing greater flexibility depending on your project requirements.

This method is more involved and requires a more complex setup compared to the JupyterHub option.

### Running Rancher RStudio
If not already logged in, log in to [rancher.cloud.e-infra.cz](https://rancher.cloud.e-infra.cz); see the [Rancher](../rancher/rancher) section.

Following the steps below, you can install the RStudio web application. This application has a persistent home directory, which means that if you delete the application and later install it again with the same name, the content of the home directory will be preserved.

<Callout type="warn">
The default project has a quota limit of 12 guaranteed CPUs and a limit of 16 CPUs total. Do not select more than 10 guaranteed CPUs and more than 14 CPUs total. If you need more, just [ask](mailto:k8s@ics.muni.cz). This may be increased in the future, so a request for more CPUs can be made.
</Callout>

### Select Application to Run

Navigate through `Only User Namespaces` (1), `Apps & Marketplace` (2), `Charts` (3), `cerit-sc` (4), and select `RStudio` (5). See the screenshot below.

![selectapp](/img/ceritsc/apps/rstudio/selectapp.png)

### Install the Application

When you click on the chart, hit `Install` to continue.

![selectapp](/img/ceritsc/apps/rstudio/selectversion.png)

Now you can install the RStudio application. In most cases, keep both `Namespace` (1) and `Name` (2) intact; however, you can select a namespace as desired except `default`. The `default` namespace is available but is not meant to be used. The `Name` will be in the URL to access the application. The `Name` must be unique in the `Namespace`, i.e., you cannot run two or more instances with the same `Name` in the same `Namespace`. If you delete the application and later install it again while preserving its `Name`, the content of the home directory will be preserved.

![appinst](/img/ceritsc/apps/rstudio/appinst.png)

In the first part of the form, you choose an R image, which selects the R version. Images with the `Full` tag contain most system libraries and also allow you to install additional system packages using the `fakeroot` command, like `fakeroot apt-get install libssl-dev`. However, if the application is restarted or reinstalled, all installations using `fakeroot` are lost and have to be installed again.

![appinst](/img/ceritsc/apps/rstudio/appform1.png)

In the second part of the form, you select an access password. Please avoid characters like `{` and `}`. A non-trivial password is strongly recommended; however, it is also strongly recommended not to use a password you already use elsewhere. The username will be just **`rstudio`**.

![appform1](/img/ceritsc/apps/rstudio/appform2.png)

In the third part of the form, you can select **e-infra** storage (3) to connect to the application. If you check `External Storage`, only `storage-brno12-cerit.metacentrum.cz` is supported. If you want to connect this storage, follow [the tutorial on creating the storage](../other/storagesecrets). On the [storage secrets site](https://storagesecrets.cloud.e-infra.cz), you will click the first option `Create Samba password for storage-brno12-cerit.metacentrum.cz`. This storage is mounted to the `/home/rstudio/data` directory.

You can also select the persistent `/opt` volume (2), which is used for installed packages via the `conda` installer (see below). The persistent `/opt` preserves installed packages across `rstudio` restarts.

The persistent `home` (1) preserves the content of the home directory across `rstudio` restarts.

![appinst](/img/ceritsc/apps/rstudio/appform3.png)

In the fourth part of the form, you can select requested resources. This step is optional. The `Minimum` CPU or RAM is the guaranteed amount of CPU and RAM; the system reserves these resources for the application. However, the application can exceed guaranteed resources up to the `Maximum`. In this case, resources are not exclusive and can be shared among other applications. If the application exceeds the `Maximum` CPU, it gets limited; if it exceeds the `Maximum` RAM, it gets terminated (you will see an OOMKill report) and restarted. See the note above about maximum values.

![appform2](/img/ceritsc/apps/rstudio/appform4.png)

### Wait for Application to Start

When you click `Install`, you will see an installation log. Once you see `SUCCESS` (see the screenshot below), the application is running.

![apphelm](/img/ceritsc/apps/rstudio/apphelm.png)

### Login to the Running Instance

Once the application is running, navigate through `Service Discovery` (1) and `Ingresses` (2). You will see `Ingresses`. If you see `cm-acme-http-solver...` (3), wait until it disappears. Once you see `rstudio` or whatever `Name` you used in the previous steps, you can click on the Target (4) to log in to the application.

![appacme](/img/ceritsc/apps/rstudio/appacme.png)

You will see a login window; use **`rstudio`** as the login name and the selected password from the form.

![applogin](/img/ceritsc/apps/rstudio/applogin.png)

## Delete Running Instance

If you no longer need the application, you can delete it. Just navigate to `Apps & Marketplace` (1), `Installed Apps` (2), select the application (3), and click `Delete` (4). The data in the home directory is not deleted. Running the application again with the same `Name` restores access to the home directory folder.

![appdel](/img/ceritsc/apps/rstudio/appdel.png)

## Install Additional Packages

As of chart version **1.4**, it is possible to use the `conda` or `mamba` tools to install additional packages typically used in MetaCentrum. They are installed into the `/opt/conda` directory. For example, in the `rstudio` `terminal` (1), type `mamba install mc` (3) to install the `mc` package. If you see `(base)` (2) at the beginning of the prompt, all paths are set correctly to use `conda` installed packages. If you do not see `(base)`, type `/opt/conda/bin/conda init`, close the `terminal`, and run a new one. This action is required only once.

![terminal](/img/ceritsc/apps/rstudio/terminal.png)

### Installing in Sensitive Cloud

If you are running RStudio in the Sensitive Cloud, remember that the R session does not have a direct connection to the Internet. If you need to install packages, you will need to set up a proxy:

1. As shown below, click the `New Blank File` button in the lower right panel, select `Text File`, and enter the name `.Renviron` (including the leading dot!).

   ![blanktext](/img/ceritsc/apps/rstudio/blanktext.png)
   ![renviron](/img/ceritsc/apps/rstudio/renviron.png)

2. Paste the following into the `.Renviron` file and save it (the red arrow):

   ```bash
   HTTPS_PROXY=http://proxy.ics.muni.cz:3128
   NO_PROXY='10.0.0.0/8,10.43.0.1,.svc.cluster.local,.cloud.trusted.e-infra.cz'
   ```

   ![renviron-content](/img/ceritsc/apps/rstudio/renviron-content.png)

3. Restart the R session:

   ![restartsession](/img/ceritsc/apps/rstudio/restartsession.png)
