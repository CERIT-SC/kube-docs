## Samba Server
The Samba server can be used to expose Persistent Volume Claims via the CIFS/SMB protocol as a network drive reachable at a specified **URL** in the form of `\\[namespace]-[samba_name].dyn.cloud.e-infra.cz\data`. Persistent Volume Claims (PVCs) are used as storage for running applications in Kubernetes. If you want to upload or download data to or from a PVC using a GUI, the Samba server provides a convenient way to do so.

### Prerequisites

<Callout type="info">
The Samba server only works with existing PVCs. Therefore, make sure your PVC already exists before proceeding.
</Callout>

### Installation
1. In the Rancher GUI, check the name of the PVC you would like to expose. In this example, we will expose a PVC named `matlab-home` in the namespace `spisakova-ns`.

![pvcs](/img/ceritsc/apps/samba-images/pvc.png)

2. Navigate to all available applications and select `samba`, then click the install button in the top-right corner.

![samba](/img/ceritsc/apps/samba-images/charts.png)

3. Select the namespace where the application will be deployed. You must choose **the same** namespace as the PVC you want to expose. In this example, we select the namespace `spisakova-ns`. Choose a name for your Samba application that will form part of the final URL; the name must be unique within the namespace. In this example, we will use `samba-matlab`.

![samba-basic](/img/ceritsc/apps/samba-images/basic.png)

4. In the server settings, set a password for the Samba server. Select the PVC you want to expose; in this example, we select `matlab-home`.

![samba-server-settings](/img/ceritsc/apps/samba-images/serversettings.png)

5. Your network drive will only be available within the MUNI network or after connecting to the MUNI VPN.

<Callout type="warn">
Your network drive will only be available within the MUNI network or after connecting to the MUNI VPN.
</Callout>

![samba-public-expose](/img/ceritsc/apps/samba-images/expose.png)

6. Wait until the Samba server is installed; it should take a few seconds.

### Connection
The final URL is composed of the selected namespace and Samba application name. In our case, we can see the name (`samba-matlab`) and namespace (`spisakova-ns`) next to the green `Deployed` status (which indicates successful installation along with the SUCCESS message in the log boxes at the bottom of the page). Therefore, the final URL is `spisakova-ns-samba-matlab.dyn.cloud.e-infra.cz`. **The username is always `user`, and the password is the one you chose when setting up the application.**

1. **Linux** — First, install `cifs-utils` on Ubuntu/Debian OS. After installation, enter the command:

```bash
mount.cifs //[namespace]-[samba_name].dyn.cloud.e-infra.cz\data [mount_location] -o username=user
```

Provide the password when prompted. Then, you can change to the location chosen as the mount point and work with the network drive as a regular directory.

![samba-linux-command](/img/ceritsc/apps/samba-images/linux-command.png)

2. **Windows** — Open File Explorer from the taskbar or the Start menu, or press the Windows logo key + E. Select This PC from the left pane. Then, on the Computer tab, select Map network drive. In the Folder box, type the path:

```
\\[namespace]-[samba_name].dyn.cloud.e-infra.cz\data
```

Select "Log in as another account" and provide credentials.

![samba-windows-choose](/img/ceritsc/apps/samba-images/windows-choose.png)

![samba-windows-server](/img/ceritsc/apps/samba-images/windows-server.png)

![samba-windows-login](/img/ceritsc/apps/samba-images/windows-login.png)

![samba-windows-in](/img/ceritsc/apps/samba-images/windows-in.png)

3. **macOS** — Open Safari and enter a URL in the form of:

```
smb://[namespace]-[samba_name].dyn.cloud.e-infra.cz\data
```

The `\data` part is required. Click `Allow`, provide the credentials as a registered user (username is `user`, password is the one you set). Connect, and the network drive will be available in Finder. You can later unmount the drive using the unmount button.

![samba-mac-allow](/img/ceritsc/apps/samba-images/mac-allow.png)

![samba-mac-connect](/img/ceritsc/apps/samba-images/mac-connect.png)

![samba-mac-unmount](/img/ceritsc/apps/samba-images/mac-unmount.png)
