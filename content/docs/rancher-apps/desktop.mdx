## Running Desktop

If you are not already logged in, log in to [rancher.cloud.e-infra.cz](https://rancher.cloud.e-infra.cz). See the [Rancher](../rancher/rancher) section for details.

You can run a desktop application by following the steps below. This application can have a persistent home directory, which means that if you delete the application and later reinstall the application under the same name, the contents of the home directory will be preserved. It is also possible to connect some storage from e-INFRA CZ.

<Callout type="warn">
The default project has a quota limit of 12 guaranteed CPUs and 16 CPUs total. Do not select more than 10 guaranteed CPUs or exceed 14 total CPUs. If you need more resources, [ask](mailto:k8s@ics.muni.cz). These limits may be increased in the future.
</Callout>

### Select the Application to Run

Make sure you do not have a namespace selected and see "User Namespaces Only" (1) at the top of the Rancher page.

Navigate through "App & Marketplace" (2), "Charts" (3), limit charts to "cerit-sc" (4), and select "desktop" (5). See the screenshot below.

![selectapp](/img/ceritsc/apps/desktop/selectapp.png)

### Selecting the Version of the Application

When you click on the chart, you can select the version of the application as shown below. Chart versions may vary over time. Press "Install" to continue.

![selectversion](/img/ceritsc/apps/desktop/selectversion.png)

### Installing the Application

Now you are ready to install the desktop application. In most cases you will leave both "Namespace" (1) and "Name" (2) as they are, but you can choose any namespace except "default". The "default" namespace is available but is not intended for regular use. The "Name" will be part of the URL used to access the application. The "Name" must be unique within the "Namespace", meaning you cannot run two or more instances with the same "Name" in the same "Namespace". If you delete the application and later reinstall it using the same "Name", the contents of the home directory will be preserved if this option is enabled.

![appinst](/img/ceritsc/apps/desktop/appinst.png)

In the first part of the form you select the "Desktop" "Image". Currently LTS Ubuntu 18, 20, and 22 are available, but available images may vary over time.

![appform1](/img/ceritsc/apps/desktop/appform1.png)

In the second part of the form, select the display protocol. The default is [VNC](https://cs.wikipedia.org/wiki/Virtual_Network_Computing). You will need a VNC viewer program such as [realvnc](https://www.realvnc.com/en/connect/download/viewer/) or the `vncviewer` command on most Linux distributions. On macOS, type `vnc://host` in the Safari browser, replacing "host" according to the instructions below. Do not press "Install" until the form is complete. When using *VNC*, only software rendering is available; no 3D acceleration is possible.

If VNC is not selected, the *WebRTC* method will be used. This option is still in beta, but full 3D OpenGL acceleration is available.

<Callout type="info">
*WebRTC* is available in Chromium-based web browsers such as Google Chrome or Microsoft Edge, and in Apple Safari. Notably, it does not work in Mozilla Firefox.
</Callout>

![appform2](/img/ceritsc/apps/desktop/appform2.png)

In the third part of the form you choose a "password". This password is used for VNC login. If VNC is not selected, you must also fill in a "username"; these credentials will be used in the browser to connect to the *WebRTC* session.

#### For VNC
![appform3](/img/ceritsc/apps/desktop/appform3.png)

#### For WebRTC
![appform3-rtc](/img/ceritsc/apps/desktop/appform3-rtc.png)

In the fourth part of the form, you select whether you want a persistent home, meaning a home directory that will be preserved even if you uninstall the application. Note: the persistent home is bound to the application name from the beginning of the installation form. For example, if you set the name to "desktop", the persistent home will be bound to the name "desktop". If you later select the name "desktop-0", you will get a new home directory bound to the name "desktop-0".

In this part you can select **e-INFRA CZ** storage to connect to the application. If you check "External Storage", additional options will appear. You can select the storage and credentials. Currently only `storage-brno12-cerit.metacentrum.cz` is supported. The username is your e-INFRA CZ ([MetaCentrum](https://metavo.metacentrum.cz/)) login, and the password **is not** your MetaCentrum password but a different one set by the administrator. [Ask](mailto:k8s@ics.muni.cz) if you need to set it. We are preparing a more convenient method. This storage will be mounted to the `/storage` directory.

![appform4](/img/ceritsc/apps/desktop/appform4.png)

In the fifth part of the form you can select requested resources. This step is optional. The "Minimum" CPU or RAM is a guaranteed amount of CPU and RAM; the system reserves these resources for the application. However, the application can exceed the guaranteed resources up to the "Maximum". In this case, the resources are not exclusive and can be shared with other applications. If the application exceeds the "Maximum" CPU, it will be throttled; if it exceeds the "Maximum" RAM, it will be terminated (you will see an OOMKill report) and restarted. See the note above about maximum values.

![appform5](/img/ceritsc/apps/desktop/appform5.png)

### Wait for Application to Start

When you press "Install", you will see the installation log. When you see "SUCCESS" (1) (see screenshot below), the application is running. For the *VNC* version, you will see a URL that should be passed to a VNC viewer (2); for the *WebRTC* version, you will see a URL to open in a browser (2).

<Callout type="warn">
If the entered storage password is incorrect, the application will remain pending indefinitely. In this case, delete the application and start again.
</Callout>

### Connect to the Running Instance

Once the application is running, for the *VNC* version, navigate through "Service Discovery" (1) and "Services" (2), hover your mouse over "Target" (3), and depending on the browser used, you should see the target URL (4). The Chrome browser shows it in the lower left corner. This is the IP address and port you need to pass to your `vncviewer` application or enter in the Safari navigation bar, for example `vnc://147.251.253.246`. Alternatively, you can use the viewer URL from the screenshots above (2).

For *WebRTC*, instead of "Services", navigate to "Ingresses" (5) and you will see the full URL to click to start the *WebRTC* connection.

The *VNC* client will ask for a password. Enter the password from the form. The *WebRTC* connection will ask for a username and password; these **are not** your MetaCentrum username and password but the ones you entered at the beginning of the form.

## Delete Running Instance

If you no longer need the application, you can delete it. Go to "Apps & Marketplace" (1), "Installed Applications" (2), select the application (3), and press "Delete" (4). The data in the home directory will not be deleted if you selected persistent home. Running the application again with the same name will restore access to the home folder.

![appdel](/img/ceritsc/apps/desktop/appdel.png)

## Installing Additional Software

It is possible to install additional software into a running desktop using either system install or `conda` system.

### System Install

The `apt-get install`, `apt install`, or `dpkg -i` commands can be used to install any package into the running desktop. However, if the desktop is rebooted, all installed packages are lost and must be reinstalled. All mentioned commands are shell aliases using `fakeroot`, and these aliases only work in `bash`. If you are using another shell, you may need to use e.g. `fakeroot apt-get install [package]`.

### Conda

We strongly recommend using the `mamba` tool instead of `conda` as it is faster. If you set up a virtual conda environment in your home directory, everything installed with `conda` or `mamba` will be persistent. For more information, see the official conda documentation (https://conda.io/projects/conda/en/latest/user-guide/tasks/manage-environments.html#managing-environments), especially the section "Specifying a location for an environment".
