## New Matrix User Platform for the LLM topics

The topic of LLMs is generating significant interest among MetaCentrum users, with an increasing number of questions, discussions, and experiences worth sharing. We have therefore launched a dedicated communication channel on Matrix, a platform similar to Discord that runs locally within the e-INFRA CZ infrastructure.

Two channels are currently available:
- **LLM-General** – for sharing experiences, know-how, tips, and best practices among users,
- **LLM – Status** – for information about outages and the current status of the services.

Our goal is to gradually move the community discussion around LLMs to this space, where users can share their experiences, knowledge, and best practices, and help each other.

For now, we are testing how this type of communication platform works in the MetaCentrum environment. If it proves useful, we may expand it to cover other topics in the future.

<Callout type="info">
**Matrix does not replace email or RT**. Routine questions and requests directed to MetaCentrum/CERIT-SC will continue to be handled through the standard RT process. Matrix is primarily intended for community communication and sharing knowledge and experiences among users.
</Callout>

## Welcome Screen & Initial Setup

When signing in for the first time, you will see the welcome screen and be guided through two initial setup tasks before accessing your messages:

1. **Encryption setup**
2. **Notification settings**



### Setting Up Encryption

Matrix uses **End-to-End Encryption (E2EE)** to secure your messages.

- Only conversation participants can read messages.
- Server administrators cannot inspect your encrypted communication.
- Your chats remain completely private.

To start configuring key backup, click **Continue**.

![Encryption setup welcome](/img/ceritsc/matrix-welcome.png)


#### Get Your Recovery Key

Matrix will generate a unique **Recovery Key**.

![Encryption setup](/img/ceritsc/matrix-encryption.png)

![Get recovery key](/img/ceritsc/matrix-get-key.png)

This key is essential to:
- Restore encrypted message history.
- Verify new devices.
- Recover access if you log out on all sessions.

<Callout type="warning">
**Important:** The Recovery Key is displayed **only once**.
</Callout>

#### Save Your Recovery Key

Store your key in a safe, persistent location. Recommended options:

- A secure password manager
- An encrypted file store
- A printed physical copy stored securely

![Save recovery key](/img/ceritsc/matrix-save-key.png)

<Callout type="warning">
If you lose your Recovery Key and have no other verified active devices, you may permanently lose access to your encrypted message history.
</Callout>


#### Verify via Recovery Key

When signing in on a new device, Matrix will ask for this key to unlock your historical chats.

- Enter or paste your **Recovery Key**.
- Click `Finish set up`.

![Enter recovery key](/img/ceritsc/matrix-enter-key.png)

Once entered, your encrypted conversations will be decrypted and available on the new device.


### Notifications Setup

Element will request permission to send browser notifications. 

Enable notifications to receive real-time alerts for:
- Direct messages
- `@mentions`
- Room invitations
- New activity in active rooms

![Enable notifications](/img/ceritsc/matrix-notification.png)

<Callout type="warning">
You can fine-tune notification preferences anytime in your account settings.
</Callout>

## Joining Public Rooms

Matrix hosts central public channels. Two main rooms are available for discussion regarding the infrastructure's LLM services:

1. **LLM - Status** (System updates, releases, and outages)
2. **LLM - General** (Open discussion on LLM topics and usage)

### How to Find and Join Public Rooms:

1. Click **Explore Rooms** (Room Directory).
2. Enter a keyword (e.g., `LLM`) into the search bar.
3. Browse the room directory list.
4. Click **View** to preview a room.

![Search rooms](/img/ceritsc/matrix-searchrooms.png)

5. Click **Join the discussion** to become a member.

![Join room](/img/ceritsc/matrix-add2room.png)

Joined rooms will now remain saved on your sidebar home interface for quick access.

![Home page with rooms](/img/ceritsc/matrix-home2.png)

<Callout type="warning">
Private or moderated rooms may require administrator approval before access is granted.
</Callout>


### Inviting Members to a Room

If you have permission to invite members to a specific room:

1. Open the designated room.
2. Open the **Room Information** panel (top right).
3. Select **Members**.
4. Click **Invite**.
5. Search for the user (must be a registered Matrix user).
6. Send the invitation.

The invited user will receive an in-app notification to accept or decline the room invitation.

<Callout type="warning">
**E-mail invitations are not supported**.
Inviting external users via email requires third-party plugins that transmit internal data outside our infrastructure, which is disabled to comply with e-INFRA CZ security policies. Users must first register their account before they can be invited or found in search.
</Callout>

## How to Set Up the Hermes Agent in Matrix 

This guide walks you through deploying and configuring the Hermes agent in your Matrix private room via a web browser.

### Create a Matrix Room
First, create a new private room in your Matrix web client. 

<Callout type="warning">
**IMPORTANT:** The room **MUST NOT BE ENCRYPTED**. If end-to-end encryption is enabled, the agent will not be able to transfer files to and from the chat.
</Callout>

![matrix new room](/img/ceritsc/matrix-new-roomEN.jpg)

### Get Your LLM API Key
Make sure you have your [LLM API key generated](/docs/ai-as-a-service/chat-ai#creating-an-api-key). Copy it to your clipboard, as you will need it during the Rancher deployment phase.

### Generate the Agent Configuration
- Navigate to the agent portal at [https://app.matrix.cloud.e-infra.cz](https://app.matrix.cloud.e-infra.cz).
- Follow the on-screen instructions to generate a new agent. The name of the agent can not be changed.
- The system will output a block of environment variables (`env`). **Copy this entire text snippet**, as you will need it during the deployment phase in Rancher.

![generate agent](/img/ceritsc/matrix-create-agent.png)
![agent provisioner](/img/ceritsc/matrix-agent-provisioner.png)

### Configure the Deployment in Rancher

- Log in to your [Rancher dashboard](https://rancher.cloud.e-infra.cz) and initiate the deployment for the `matrix-hermes` application.

![hermes rancher](/img/ceritsc/matrix-hermes-rancher.png)

- Locate the `matrix-hermes` deployment, type in a name for it, and click **Next**.

![matrix rancher2](/img/ceritsc/matrix-hermes-rancher2.png)

3. During the configuration step, you will be asked to provide the following parameters:
   - **LLM API Key:** Paste the key you prepared in Step 2.
   - **Matrix Room ID:** Paste the internal ID of the room you created in Step 1. 
     **Note**: You can find this ID in the URL when you open the Matrix room in your browser. It looks something like this: `KeYNIOhcYaqpyBoGQN:matrix.cloud.e-infra.cz`
   - **Environment Variables:** Paste the complete `env` block you copied from the agent portal during agent configuration.

<Callout type="info">
**Tip: Set Namespace Permissions**
During the installation process, you will be prompted to select the agent's access level to your namespace. Choose the appropriate level for your use case:
   * None
   * Read-only
   * Full access

After initiating the installation in Rancher, it is highly recommended to check the logs of the deployed pod. This allows you to verify that the agent booted up successfully and connected without errors.
</Callout>

- Once all configurations are correctly filled out, click **Install** to deploy the `matrix-hermes` application in Rancher.

### Invite the Agent to your Matrix Room
Go back to your Matrix client, open the unencrypted room you created, and invite the newly created Hermes agent user to join.

![matrix hermes agent invitation](/img/ceritsc/matrix-hermes-agentinvitationEN.jpg)

Type the agent name you created to search for it, and send the invite.

![matrix hermes agent invitation2](/img/ceritsc/matrix-hermes-agentinvitationEN2.jpg)

Everything is set up! You can now start communicating with your Hermes agent directly in the Matrix room.

## Quick Security & Best Practices Summary

- **Safeguard your recovery key:** Keep it stored safely in a password manager. Loss of this key means losing historical encrypted messages.
- **Configure notifications:** Ensure device notifications are active so you don't miss important user mentions or room invites.
- **Use direct messages vs. rooms:** Use DMs for private 1-on-1 chats and Rooms for group projects and topic discussion.
- **Verify devices:** Always verify newly logged-in mobile or browser sessions to ensure continuous end-to-end encryption integrity.

Organization and Structure

- **Separate topics**: Use dedicated text channels for different tasks or interests.
- **Use threads**: Reply to specific messages using threads so you don't clutter the main chat.
- **Post in the right places**: Always check whether you are writing in the appropriate channel for that topic.

Communication Rules

- **One message is enough**: Don't write every word on a separate line; write the whole thought at once.
- **Tag with discretion**: Only use @mention when it's genuinely urgent or directed at a specific person.
- ** Use reactions**: Emoji reactions can often replace an entire message like "I agree" or "understands."
- **Format your text**: Put long code snippets or texts into code blocks or hide them under spoilers so they don't get in the way.
