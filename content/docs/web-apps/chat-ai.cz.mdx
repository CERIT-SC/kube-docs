## Úvod

Open WebUI je rozhraní chatbotu poháněné umělou inteligencí, které poskytuje bezpečný, lokálně provozovaný přístup k pokročilým jazykovým modelům pro chatování, programování, zpracování dokumentů a generování obrázků. Tyto modely jsou také dostupné prostřednictvím zdokumentovaného rozhraní REST API a lze je propojit s dalšími aplikacemi, jako je například Visual Studio. Tato dokumentace poskytuje pokyny, jak se přihlásit, používat modely, generovat obrázky a vytvářet API klíč. Naše služby umělé inteligence fungují zcela v rámci zabezpečené infrastruktury e-INFRA CZ – vaše data nikdy neopouštějí toto prostředí

## Přístup k Open-WebUI

K **Open-WebUI** můžete přistupovat na adrese [https://chat.ai.e-infra.cz](https://chat.ai.e-infra.cz).
Pro používání této služby je vyžadován platný účet **MetaCentrum** a **e-INFRA CZ** nebo **Masarykovy univerzity**.



### Získání přístupu

#### Pro členy Masarykovy univerzity
Pokud jste aktivním členem **Masarykovy univerzity v Brně** (zaměstnanec nebo student), následujte [tento odkaz](https://signup.e-infra.cz/registrar/?vo=e-infra.cz&group=projects%3Achat-ai&targetnew=https%3A%2F%2Fchat.ai.e-infra.cz&targetexisting=https%3A%2F%2Fchat.ai.e-infra.cz&targetextended=https%3A%2F%2Fchat.ai.e-infra.cz) pro podání žádosti o přístup.  
Váš přístup bude **automaticky schválen** a po dokončení procesu se budete moci ihned přihlásit.

#### Pro ostatní akademické a výzkumné uživatele
If you are a member of another academic or research institution in the Czech Republic (within **e-INFRA CZ**), please follow [this link](https://metavo.metacentrum.cz/en/application/form) to request a **MetaCentrum account**.

## Logging In

1. Open your web browser and navigate to https://chat.ai.e-infra.cz.
2. Click on the Login button.
3. Select the option to log in with e-INFRA CZ.
4. Once logged in, you will be redirected to the Open-WebUI dashboard.

## Using AI Models

Open-WebUI provides access to various AI models for text generation. To use them:

1. After logging in, navigate to the chat interface.
2. Select a model from the available options in the dropdown menu.
3. Type your query or request in the input field.
4. Press Enter or click Submit to receive a response from the selected model.
5. **Do not hesitate to scroll through the model list!** There are more models available. 👇
