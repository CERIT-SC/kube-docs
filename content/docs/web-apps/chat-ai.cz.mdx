## Úvod

Open WebUI je rozhraní chatbotu poháněné umělou inteligencí, které poskytuje bezpečný, lokálně provozovaný přístup k pokročilým jazykovým modelům pro chatování, programování, zpracování dokumentů a generování obrázků. Tyto modely jsou také dostupné prostřednictvím zdokumentovaného rozhraní REST API a lze je propojit s dalšími aplikacemi, jako je například Visual Studio. Tato dokumentace poskytuje pokyny, jak se přihlásit, používat modely, generovat obrázky a vytvářet API klíč. Naše služby umělé inteligence fungují zcela v rámci zabezpečené infrastruktury e-INFRA CZ – vaše data nikdy neopouštějí toto prostředí

## Přihlášení

1. Otevřete webový prohlížeč a přejděte na adresu https://chat.ai.e-infra.cz.
2. Klikněte na tlačítko Login.
3. Vyberte možnost přihlášení pomocí e-INFRA CZ.
4. Po úspěšném přihlášení budete přesměrováni na Open-WebUI dashboard.

## Používání AI modelů

Open-WebUI poskytuje přístup k různým modelům umělé inteligence pro generování textu. Chcete-li je používat:

1. Po přihlášení přejděte do rozhraní chatu..
2. Vyberte model z dostupných možností v rozbalovacím menu.
3. Do vstupního pole napište svůj dotaz nebo požadavek.
4. Stiskněte Enter nebo klikněte na Odeslat, abyste obdrželi odpověď od vybraného modelu.
5. **Neváhejte procházet seznam modelů!** Je jich k dispozici více. 👇

### Aktuálně dostupné modely (k 07/31/2025)

Naše modely rozdělujeme do tří skupin::

1. **Garantované modely** – Stabilní modely udržované pro dlouhodobou dostupnost. Jakékoli aktualizace nebo náhrady budou oznámeny na této stránce a prostřednictvím bannerů ve WebUI.
2. **Experimentální modely** – Mohou se měnit v rámci optimalizace zdrojů nebo testování nových funkcí.
3. **Zastaralé modely** – Momentálně funkční, ale určené k postupnému vyřazení z provozu.

<Callout type="info">
Pro zjištění přesných názvů modelů si zobrazte seznam modelů, jak je uvedeno [níže](#models-for-api-interface). Při přístupu z externího prostředí musíte používat přesné názvy modelů, například `llama3.3:latest`.

Názvy modelů rozlišují velká a malá písmena a mohou obsahovat verzní označení jako `:latest` nebo specifické formáty kvantizace.
</Callout>

#### Embedding Modely

Open WebUI v současnosti nepodporuje přístup k embedding modelům prostřednictvím API (i když jsou kompatibilní s API OpenAI). Z tohoto důvodu momentálně nejsou přes API Open WebUI dostupné žádné embedding modely.  

Uživatelé však mohou požádat o přístup na základě IP adresy k systému **vLLM**, který podporuje embedding modely.

## Vytvoření API klíče

Pro používání API Open-WebUI je potřeba vygenerovat API klíč.

1. Přejděte do sekce Nastavení v rozhraní Open-WebUI.
2. Přejděte na Účet.
3. Klikněte na API klíče (zobrazit).
4. Ignorujte JWT token a zvolte API klíč – buď vygenerujte nový, nebo zobrazte existující.
5. Zkopírujte vygenerovaný API klíč a bezpečně si ho uložte.
6. Tento klíč používejte v API požadavcích k ověření a přístupu ke službám Open-WebUI.
7. Adresa koncového bodu (endpoint) API je: [https://chat.ai.e-infra.cz/api/](https://chat.ai.e-infra.cz/api/).

Pro rozhraní API byste měli zjistit přesné názvy modelů pomocí příkazů jako např. `curl` a `jq`, přičemž TOKEN nahraďte svým skutečným tokenem.

```shell
curl -H "Authorization: Bearer TOKEN" https://chat.ai.e-infra.cz/api/models | jq .data[].id
```
