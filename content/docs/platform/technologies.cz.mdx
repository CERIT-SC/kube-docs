## AI
Umělá inteligence (AI) umožňuje systémům provádět úkoly, které běžně vyžadují lidskou inteligenci, jako je uvažování, učení a rozhodování.
Zkoumáme aplikace AI ve výzkumu, automatizaci a škálovatelných výpočetních prostředích.

## Bash
Bash je unixový shell a jazyk příkazů pro automatizaci úkolů a správu systémů.
Je nezbytný pro skriptování workflow, správu systému a automatizaci DevOps.

## Calico
Calico je řešení pro síťování a síťovou bezpečnost pro kontejnery, virtuální stroje a nativní workloady založené na hostitelích.
Poskytuje škálovatelné síťování a robustní vynucování zásad v prostředích Kubernetes.

## Ceph
Ceph je distribuovaný úložný systém navržený pro výkon, spolehlivost a škálovatelnost.
Poskytuje sjednocené objektové, blokové a souborové úložiště na jedné platformě.

## Cilium
Cilium je open-source řešení pro síťování, pozorovatelnost a bezpečnost pro cloud-nativní prostředí.
Používá technologii eBPF pro efektivní a bezpečné operace datové roviny v Kubernetes.

## CloudNativePG
CloudNativePG je Kubernetes operátor pro správu PostgreSQL clusterů.
Zjednodušuje nasazení, škálování a vysokou dostupnost databází PostgreSQL v cloudových prostředích.

## CSS
Kaskádové styly (CSS) definují, jak jsou HTML prvky zobrazeny na webových stránkách.
Používáme CSS k vytváření čistých, responsivních a vizuálně přitažlivých rozhraní.

## Docker
Docker je platforma pro vývoj, přepravu a spouštění aplikací v kontejnerech.
Zajišťuje konzistentní prostředí napříč vývojem, testováním a produkcí.

## etcd
etcd je distribuovaný úložiště klíč-hodnota používané pro správu konfigurace a zjišťování služeb.
Slouží jako datová páteř pro Kubernetes a jiné distribuované systémy.

## FumaDocs
FumaDocs je platforma pro dokumentaci a správu znalostí přizpůsobená pro vědecké a technické projekty.
Pomáhá týmům efektivně vytvářet, organizovat a sdílet strukturované dokumenty, čímž zlepšuje spolupráci a reprodukovatelnost.

## Git
Git je distribuovaný systém pro správu verzí pro sledování změn ve zdrojovém kódu.
Podporuje spolupráci při vývoji a udržuje podrobnou historii změn projektu.

## GitHub/GitLab
GitHub a GitLab jsou platformy pro správu verzí, spolupráci a automatizaci CI/CD.
Umožňují bezproblémovou revizi kódu, sledování problémů a workflow DevOps.

## Golang
Golang (Go) je staticky typovaný, kompilovaný jazyk vyvinutý společností Google.
Je známý pro svou jednoduchost, podporu souběžnosti a efektivitu při budování škálovatelných systémů.

## Grafana
Grafana je open-source platforma pro analytiku a monitorování.
Vizualizuje data z více zdrojů a poskytuje reálné dashboardy pro pozorovatelnost.

## Harbor
Harbor je open-source registr obrazů kontejnerů s funkcemi pro bezpečnost a kontrolu přístupu.
Pomáhá spravovat, skenovat a distribuovat obrazy kontejnerů napříč prostředími.

## HTML
HyperText Markup Language (HTML) je základem struktury webového obsahu.
Používáme ho k vytváření přístupných a sémantických webových aplikací.

## IBM Storage Scale
IBM Storage Scale (dříve GPFS) je vysoce výkonný clusterový souborový systém.
Poskytuje škálovatelné a spolehlivé úložiště pro rozsáhlá data a prostředí HPC.

## Jupyter/JupyterLab/JupyterHub
Nástroje Jupyter umožňují interaktivní výpočet a analýzu dat pomocí notebooků.
Podporují spolupráci při výzkumu a reproducibilní vědecké workflow.

## Kubernetes
Kubernetes je open-source platforma pro automatizaci nasazení, škálování a správu kontejnerů.
Efektivně koordinuje moderní cloud-nativní aplikace napříč clustery.

## Linux
Linux je open-source operační systém známý svou stabilitou, flexibilitou a bezpečností.
Napájí servery, clustery a cloudová prostředí v různých odvětvích.

## Nextflow
Nextflow je systém pro správu workflow navržený pro škálovatelné a reproducibilní vědecké pipeline.
Zjednodušuje spouštění složitých analýz v různých výpočetních prostředích, včetně cloudu a HPC.

## NGINX
NGINX je vysoce výkonný webový server, reverzní proxy a load balancer.
Je široce používán pro doručování škálovatelných, spolehlivých webových aplikací.

## Node.js
Node.js je běhové prostředí JavaScriptu postavené na enginu V8 od Chrome.
Umožňuje efektivní, neblokující I/O pro budování škálovatelných serverových aplikací.

## Ollama
Ollama poskytuje nástroje pro lokální spouštění a správu velkých jazykových modelů.
Zjednodušuje nasazení AI modelů na osobní nebo privátní infrastruktuře.

## Open-WebUI
Open-WebUI je open-source webový rozhraní pro interakci s AI modely.
Umožňuje uživatelům nasazovat, testovat a spravovat modely prostřednictvím uživatelsky přívětivého webového rozhraní.

## Prometheus
Prometheus je nástroj pro monitorování a upozorňování navržený pro spolehlivost a škálovatelnost.
Sbírá metriky a integruje se bezproblémově s Grafanou pro vizualizaci.

## Puppet
Puppet je nástroj pro automatizaci infrastruktury pro správu konfigurace.
Zajišťuje konzistentní prostředí prostřednictvím deklarativních definic konfigurace.

## Python
Python je univerzální programovací jazyk známý pro jednoduchost a čitelnost.
Je široce používán v AI, datové vědě, webovém vývoji a automatizaci.

## PyTorch
PyTorch je framework pro hluboké učení nabízející flexibilní a dynamické výpočetní grafy.
Je široce používán pro výzkum AI a vývoj modelů produkční třídy.

## Rancher
Rancher je kompletní platforma pro správu kontejnerů pro clustery Kubernetes.
Poskytuje centralizované zřizování clusterů, monitorování a bezpečnost v různých prostředích.

## React
React je knihovna JavaScriptu pro tvorbu rychlých, interaktivních uživatelských rozhraní.
Propaguje architekturu založenou na komponentách a efektivní vykreslování.

## Redis
Redis je úložiště datových struktur v paměti používané jako databáze, mezipaměť a message broker.
Poskytuje vysoký výkon a nízkou latenci pro reálné aplikace.

## RKE2
RKE2 (Rancher Kubernetes Engine 2) je odlehčená, plně kompatibilní distribuce Kubernetes.
Zaměřuje se na bezpečnost, jednoduchost a kompatibilitu pro nasazení podnikové třídy.

## SGLang
SGLang je programovací framework optimalizovaný pro efektivní obsluhu velkých jazykových modelů.
Umožňuje rychlou inferenci a úsporné nasazení LLM.

## Tailwind
Tailwind CSS je utility-first CSS framework pro rychlé vytváření vlastních návrhů.
Umožňuje vývojářům stylovat aplikace přímo v značkovacím jazyce s minimální režií.

## TensorFlow
TensorFlow je komplexní open-source platforma pro strojové učení.
Umožňuje trénování modelů, nasazení a škálovatelnou inferenci na různých platformách.

## TypeScript
TypeScript je typovaný nadmnožina JavaScriptu, která se kompiluje do čistého JS.
Zlepšuje spolehlivost a škálovatelnost kódu prostřednictvím statické kontroly typů.

## vLLM
vLLM je optimalizovaný inferenční engine pro LLM navržený pro rychlost a efektivitu.
Podporuje obsluhu velkých modelů s nižšími paměťovými nároky a vyšší propustností.

## Vue.js
Vue.js je progresivní JavaScript framework pro tvorbu uživatelských rozhraní.
Zaměřuje se na jednoduchost, reaktivitu a bezproblémovou integraci s existujícími projekty.
