## AI
Umělá inteligence (AI) umožňuje systémům provádět úlohy, které obvykle vyžadují lidskou inteligenci, jako je uvažování, učení a rozhodování.
Zkoumáme aplikace AI ve výzkumu, automatizaci a škálovatelných výpočetních prostředích.

## Bash
Bash je Unixový shell a příkazový jazyk pro automatizaci úloh a správu systémů.
Je nezbytný pro skriptování pracovních postupů, systémovou administraci a DevOps automatizaci.

## Calico
Calico je síťové a síťově-bezpečnostní řešení pro kontejnery, virtuální stroje a nativní úlohy běžící na hostitelích.
Poskytuje škálovatelné síťování a robustní vynucování politik v Kubernetes prostředích.

## Ceph
Ceph je distribuovaný systém úložiště navržený pro výkon, spolehlivost a škálovatelnost.
Poskytuje jednotné objektové, blokové a souborové úložiště pod jednou platformou.

## Cilium
Cilium je open-source síťové, monitorování (observability) a bezpečnostní řešení pro cloud-nativní prostředí.
Používá technologii eBPF pro efektivní a bezpečné operace datové roviny v Kubernetes.

## CloudNativePG
CloudNativePG je Kubernetes operátor pro správu PostgreSQL clusterů.
Zjednodušuje nasazení, škálování a vysokou dostupnost PostgreSQL databází v cloudových prostředích.

## CSS
Kaskádové styly (CSS) definují, jak se HTML elementy zobrazují na webových stránkách.
Používáme CSS k vytváření čistých, responzivních a vizuálně přitažlivých rozhraní.

## Docker
Docker je platforma pro vývoj, dodávání a spouštění aplikací v kontejnerech.
Zajišťuje konzistentní prostředí napříč vývojem, testováním a produkčním provozem.

## etcd
etcd je distribuované klíč-hodnota úložiště používané pro správu konfigurace a zjišťování služeb.
Slouží jako datový základ Kubernetes a dalších distribuovaných systémů.

## FumaDocs
FumaDocs je dokumentační a znalostní platforma přizpůsobená pro vědecké a technické projekty.
Pomáhá týmům vytvářet, organizovat a sdílet strukturované dokumenty efektivně, zlepšuje spolupráci a reprodukovatelnost.

## Git
Git je distribuovaný systém správy verzí pro sledování změn ve zdrojovém kódu.
Podporuje kolaborativní vývoj a udržuje podrobnou historii změn projektu.

## GitHub/GitLab
GitHub a GitLab jsou platformy pro správu verzí, spolupráci a CI/CD automatizaci.
Umožňují bezproblémové revize kódu, sledování problémů a DevOps pracovní postupy.

## Golang
Golang (Go) je staticky typovaný, kompilovaný jazyk vyvinutý společností Google.
Je známý pro svou jednoduchost, podporu souběžného zpracování a efektivitu při budování škálovatelných systémů.

## Grafana
Grafana je open-source analytická a monitorovací platforma.
Vizualizuje data z více zdrojů a poskytuje dashboardy v reálném čase pro monitorování (observability).

## Harbor
Harbor je open-source registr kontejnerových obrazů s bezpečnostními a přístupovými funkcemi.
Pomáhá spravovat, skenovat a distribuovat kontejnerové obrazy napříč prostředími.

## HTML
HyperText Markup Language (HTML) je základem struktury webového obsahu.
Používáme ho k vytváření přístupných a sémantických webových aplikací.

## IBM Storage Scale
IBM Storage Scale (dříve GPFS) je vysoce výkonný clusterovaný souborový systém.
Poskytuje škálovatelné a spolehlivé úložiště pro rozsáhlá data a HPC prostředí.

## Jupyter/JupyterLab/JupyterHub
Nástroje Jupyter umožňují interaktivní výpočty a analýzu dat pomocí notebooků.
Podporují kolaborativní výzkum a reprodukovatelné vědecké pracovní postupy.

## Kubernetes
Kubernetes je open-source platforma pro automatizaci nasazení, škálování a správy kontejnerů.
Orchestruje moderní cloud-nativní aplikace efektivně napříč clustery.

## Linux
Linux je open-source operační systém známý pro svou stabilitu, flexibilitu a bezpečnost.
Pohání servery, clustery a cloudová prostředí napříč odvětvími.

## Nextflow
Nextflow je systém pro správu pracovních postupů navržený pro škálovatelné a reprodukovatelné vědecké datové toky.
Zjednodušuje spouštění složitých analýz napříč různými výpočetními prostředími, včetně cloudu a HPC.

## NGINX
NGINX je vysoce výkonný webový server, reverzní proxy a nástroj pro vyrovnávání zatížení.
Je široce používán pro doručování škálovatelných, spolehlivých webových aplikací.

## Node.js
Node.js je JavaScript runtime postavený na V8 enginu od Chrome.
Umožňuje efektivní, neblokující I/O pro budování škálovatelných server-side aplikací.

## Ollama
Ollama poskytuje nástroje pro spouštění a správu velkých jazykových modelů lokálně.
Zjednodušuje nasazení AI modelů na osobní nebo privátní infrastruktuře.

## Open-WebUI
Open-WebUI je open-source webové rozhraní pro interakci s AI modely.
Umožňuje uživatelům nasazovat, testovat a spravovat modely přes uživatelsky přívětivé prohlížečové rozhraní.

## Prometheus
Prometheus je sada nástrojů pro monitoring a alerting navržená pro spolehlivost a škálovatelnost.
Sbírá metriky a bezproblémově integruje s Grafanou pro vizualizaci.

## Puppet
Puppet je nástroj pro automatizaci infrastruktury pro správu konfigurace.
Zajišťuje konzistentní prostředí přes deklarativní definice konfigurace.

## Python
Python je univerzální programovací jazyk známý pro svou jednoduchost a čitelnost.
Je široce používán v AI, datové vědě, webovém vývoji a automatizaci.

## PyTorch
PyTorch je framework pro hluboké učení nabízející flexibilní a dynamické výpočetní grafy.
Je široce používán pro AI výzkum a vývoj produkčních modelů.

## Rancher
Rancher je kompletní platforma pro správu kontejnerů pro Kubernetes clustery.
Poskytuje centralizované zřizování clusterů, monitoring a bezpečnost napříč více prostředími.

## React
React je JavaScript knihovna pro vytváření rychlých, interaktivních uživatelských rozhraní.
Podporuje komponentovou architekturu a efektivní renderování.

## Redis
Redis je in-memory datové úložiště používané jako databáze, cache a zprostředkovatel zpráv.
Poskytuje vysoký výkon a nízkou latenci pro real-time aplikace.

## RKE2
RKE2 (Rancher Kubernetes Engine 2) je lehká, plně kompatibilní distribuce Kubernetes.
Zaměřuje se na bezpečnost, jednoduchost a kompatibilitu pro enterprise nasazení.

## SGLang
SGLang je programovací framework optimalizovaný pro efektivní servírování velkých jazykových modelů.
Umožňuje rychlou inferenci a úsporné nasazení LLM.

## Tailwind
Tailwind CSS je utility-first CSS framework pro rychlé vytváření vlastních designů.
Umožňuje vývojářům stylovat aplikace přímo v markupu s minimální režií.

## TensorFlow
TensorFlow je end-to-end open-source platforma pro strojové učení.
Umožňuje trénink modelů, nasazení a rozsáhlou inferenci napříč různými platformami.

## TypeScript
TypeScript je typovaná nadmnožina JavaScriptu, která se kompiluje do čistého JS.
Zlepšuje spolehlivost a škálovatelnost kódu přes statické typové kontroly.

## vLLM
vLLM je optimalizovaný LLM inferenční engine navržený pro rychlost a efektivitu.
Podporuje servírování velkých modelů s nižší paměťovou režií a vyšším throughputem.

## Vue.js
Vue.js je progresivní JavaScript framework pro vytváření uživatelských rozhraní.
Zaměřuje se na jednoduchost, reaktivitu a bezproblémovou integraci s existujícími projekty.
