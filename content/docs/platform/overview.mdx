## Computing resources for your research

CERIT-SC provides computing resources and hosted applications for research and education. Use the platform to analyse data, run computational
workflows, deploy research software, and access artificial intelligence (AI) tools.

You can start with a browser-based application or deploy your own software using containers. A container packages an application with its software dependencies, making it easier to run a consistent computing environment.

## Choose a service

### Computing resources (Kubernetes)

The platform provides CPU and GPU computing resources and storage.
Consult the [hardware overview](../platform/hw) for available systems
and the [resource quotas](../rancher/quotas) for project limits.

#### Get started

1. **Check eligibility and create an account.**
   Read the [access requirements](../platform/access), including the
   terms of use and MetaCentrum registration instructions.

2. **Choose a service.**
   Follow the relevant application guide, or start with
   [Rancher](../rancher/rancher) to deploy containerised software.
   Eligible users receive an individual project with default resource
   quotas when they first sign in to Rancher.

3. **Request resources for your research.**
   If you need a shared project for your research group or a larger
   individual quota, follow the
   [project request instructions](../rancher/reqproj).

### Run your own applications and workflows

The managed Kubernetes platform lets you run containerised research
software. Kubernetes manages how containers run on shared computing
resources; Rancher provides a web interface for working with the platform.

- Deploy applications such as MATLAB and Scipion from the
  [Rancher application catalogue](../rancher-apps/rancher-applications).
- Package your own software in a
  [container image](../docker/dockerfile).
- Manage applications through the [Rancher web interface](../rancher/rancher)
  or the [kubectl command-line tool](../kubernetes/kubectl).
- Automate deployments using [GitOps](../gitops/agentk), with configuration
  maintained in a Git repository.

### Browser-based applications

For interactive work, start with a hosted application that runs in your
browser without a local installation:

- [JupyterHub](../web-apps/jupyterhub): Work with Jupyter notebooks for
  interactive programming and data analysis.
- [BinderHub](../web-apps/binderhub): Turn a Git repository into an
  interactive computing environment.
- [Foldify](../web-apps/foldify): Use AlphaFold through a web interface
  to predict protein structures.

See each application's documentation for access requirements and
instructions.

### AI services

[AI as a Service](../ai-as-a-service/introduction) provides access to
large language models and related tools hosted within e-INFRA CZ.

- Use [Chat AI](../ai-as-a-service/chat-ai) through a browser.
- Connect your research scripts and applications through the
  [OpenAI-compatible API](../ai-as-a-service/ai-api).
- Build automated workflows with
  [n8n](../ai-as-a-service/n8n-agents).

Before uploading research data, read the
[AI data privacy policy](../ai-as-a-service/ai-data-privacy).
The chat interface and API have different data-handling characteristics.
Contact the support team to discuss requirements for sensitive or
protected data.
