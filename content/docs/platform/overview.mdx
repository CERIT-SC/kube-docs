## Computing resources for your research

CERIT-SC provides computing resources and hosted applications for research and education. Use the platform to analyse data, run computational
workflows, deploy research software, and access artificial intelligence (AI) tools.

You can start with a browser-based application or deploy your own software using containers. A container packages an application with its software dependencies, making it easier to run a consistent computing environment.

![platform](/img/ceritsc/platform-overview.png)

## New here? Start in three steps

<Cards className="grid-cols-1 gap-4 sm:grid-cols-3">

  <Card title="2. Sign in to Rancher" icon={<LogIn />} href="../rancher/rancher">
    Rancher is the web interface to the platform. Your first login creates a personal project with 20 CPUs and 40 GB of memory.

  <Card title="3. Deploy your first application" icon={<Rocket />} href="../examples/helloworld">
    Follow the Hello world tutorial to run a small web server and learn the basic Kubernetes concepts on the way.

You do not need Rancher for the browser applications. [JupyterHub](../web-apps/jupyterhub), [BinderHub](../web-apps/binderhub), which turns a Git repository into an interactive environment, and [Foldify](../web-apps/foldify) for protein structure prediction, or [Chat AI](../ai-as-a-service/chat-ai) work as soon as you have an account.

## Services

<Cards className="pt-4 grid-cols-1 gap-4 sm:grid-cols-3">

<Card title="Kubernetes" icon={<Image src={Kubernetes} alt="Kubernetes Logo" width="220"/>}>

Run containerised research software and computational workflows on shared
computing resources.

- Deploy tools from the [application catalogue](../rancher-apps/rancher-applications).
- Run your own [container images](../docker/dockerfile).
- Manage applications through [Rancher](../rancher/rancher) or
  [kubectl](../kubernetes/kubectl).

</Card>

<Card title="Interactive applications" icon={<Image src={Interactive} alt="Interactive Apps" width="220"/>}>

Use research applications in your browser without installing software locally.

- [JupyterHub](../web-apps/jupyterhub): Analyse data in Jupyter notebooks.
- [BinderHub](../web-apps/binderhub): Launch computing environments from Git repositories.
- [Foldify](../web-apps/foldify): Predict protein structures with AlphaFold.

</Card>

<Card title="AI as a Service (AIaaS)" icon={<Image src={AIllm} alt="AIaaS" width="220"/>}>

Access large language models hosted within e-INFRA CZ through a browser
or from your research software.

- Use the [Chat AI interface](../ai-as-a-service/chat-ai).
- Connect scripts through the [OpenAI-compatible API](../ai-as-a-service/ai-api).
- Review the [data privacy policy](../ai-as-a-service/ai-data-privacy)
  before uploading research data.

</Card>

</Cards>

## What do you want to do?

<Cards className="grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-3">

  <Card title="Analyse data in notebooks" icon={<NotebookPen />} href="../web-apps/jupyterhub">
    **JupyterHub.** Jupyter notebooks in your browser with prepared images and optional GPUs. Nothing to install.
  </Card>

  <Card title="Use AI models" icon={<BrainCircuit />} href="../ai-as-a-service/introduction">
    **AI as a Service.** Large language models hosted within e-INFRA CZ, available as a web chat or an OpenAI-compatible API.
  </Card>

  <Card title="Launch a ready-made application" icon={<LayoutGrid />} href="../rancher-apps/rancher-applications">
    **Application catalogue.** RStudio, MATLAB, Scipion, Overleaf and more. Fill in a short form and open the result in your browser.
  </Card>

  <Card title="Run your own software" icon={<Container />} href="../docker/dockerfile">
    **Containers.** Package your code as a container image and run it on the shared clusters.
  </Card>

  <Card title="Run workflow pipelines" icon={<Workflow />} href="../workflows/nextflow">
    **Workflows.** Nextflow and Argo pipelines with Kubernetes as the execution backend.
  </Card>

  <Card title="Work from the command line" icon={<Terminal />} href="../kubernetes/kubectl">
    **kubectl.** Manage jobs, storage and networking directly, or script your deployments.
  </Card>

  <Card title="Add a database or object storage" icon={<Database />} href="../operators/operator-summary">
    **Operators.** PostgreSQL, MinIO, OpenSearch, Spark and others, deployed with a short manifest.
  </Card>

  <Card title="Automate deployments from Git" icon={<GitBranch />} href="../gitops/agentk">
    **GitOps.** Build container images and deploy them from a GitLab repository.
  </Card>

  <Card title="Process sensitive data" icon={<ShieldCheck />} href="../sensitivecloud/account">
    **SensitiveCloud.** A separate secure environment for medical and other protected data.
  </Card>

</Cards>

## About CERIT-SC

[CERIT-SC](https://www.cerit-sc.cz) is operated by the Institute of Computer Science at Masaryk University. Together with CESNET and IT4Innovations it forms the national e-INFRA CZ research infrastructure. Looking for batch computing on HPC clusters instead? See the [MetaCentrum documentation](https://docs.metacentrum.cz).
