# User approval

When the user will apply for membership in the VO under your administration, you will receive an email with similar structure like the example in the end of this page. There you can find link, which will redirect you to the webpage with detail info about requesting user. There you can click at the link and then log in to the Perun system. Now you can Approve/Reject the user application.

If you want to approve/reject the application manually you need to login to [Perun system](perun.einfra.cesnet.cz/login) first and then select the virtual organization where you wish to manage the users applications. Then you need to click on the **Applications (1)** tile.

![perun](/img/data-care/perun/perun-approve-user1.png)

Then you can see the list of all submitted applications and their status. You can click on the **particular application (1)**, that you wish to accept/reject.

![perun](/img/data-care/perun/perun-approve-user2.png)

In the end, you can see the detail view of the application where you can click on the button **Approve/Reject (1)**.

![perun](/img/data-care/perun/perun-approve-user3.png)
