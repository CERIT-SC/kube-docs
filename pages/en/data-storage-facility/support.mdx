# Support and contacts
Below you can find elementary contact information of the CESNET Data Storage Department and coresponding information about helpdesk.

## CESNET Address

Detail contact information about CESNET Headquarters can be found at [CESNET webpage](https://www.cesnet.cz/en/contacts)

## User support

Before submitting a request, check it if you can find the answer to your question in [FAQ](../faq/faq.mdx)

The primary contact for solving the majority of problems tied to data storage operation is the address `support@cesnet.cz`. You can use the address for any comments, suggestions, technical issues as well as questions of technical manner targeted for system administrators.

<Callout type="info" emoji="ℹ️">
**Request Tracker** <br/>
All the correspondence received on e-mail address mentioned above is recorded in [Request Tracker](http://bestpractical.com/rt) system, which creates a ticket and assigns an Id number to it.
</Callout>

The author of the e-mail and all people in data storage responsible for resolving users' problems are notified about the ticket creation by e-mail. Ticket Id will show up in the subjects of all e-mails referring to given ticket. All e-mails are sorted by this ticket Id, therefore please preserve this identification in the subject of the e-mail, when replying to question of data storage staff.

When the ticket is resolved, the author is notified by e-mail about the resolution. Any other question will cause the ticket to open again.

## Recommended formulation of acknowledgement to storage department CESNET
If you are satisfied with CESNET Data Care services, we will appreciate if you can mention the name of our institution in your publication in following form:

```conf filename="acknowledgement" copy
Access to CESNET storage facilities provided by the project „e-INFRA CZ“ under the programme „Projects of Large Research, Development, and Innovations Infrastructures“ LM2018140), is (greatly) acknowledged/appreciated.
```

Usage of „appreciated“ or „acknowledged“ is up to the user, as well as whether the service will be appreciated „greatly“. Please note that the crucial part is the project number.
